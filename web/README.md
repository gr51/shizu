# 噬祖 · 诸天噬灵 —— 网页版

策划文档的**可运行实现**。`src/core/` 与 `src/data/` 零 DOM、零引擎依赖，
是后续整体移植进 Cocos 的那一层；`src/ui/` 是一次性的 DOM 外壳。

## 跑起来

```bash
node tools/serve.mjs          # → http://localhost:8123
```

无需安装任何依赖（`playwright` 只在跑 e2e 时用）。

## 验证

```bash
node --test "tests/**/*.test.mjs"   # 65 项单元测试
node tools/simulate.mjs 400         # 长线成长曲线模拟
node tools/e2e.mjs                  # 无头浏览器实跑一局（需先起 serve）
```

测试是照着《噬祖-开发实现指南》十四章那**九条编码红线**逐条写的：

| 红线 | 内容 | 守护它的测试 |
|---|---|---|
| 1 | 位面不设固有强度，禁止按位面手写强度表 | 12 位面同 D 下敌人数值必须相同 |
| 2 | D 在开副本时快照 | 局内暴富后 D 与敌人数值不得变 |
| 3 | 不匹配位面零技能，但装备照掉（×1.5） | 5000 次属性通道三选一不得漏出技能 |
| 4 | 互斥权重 ×0 必须真生效 | 激活渡劫后 10000 次抽取不得出现尸海 |
| 5 | dynFactor 恒钳制 [0.70, 1.50] | 连胜/连败/混合各数千次不得越界 |
| 6 | 存档原子写 | 整局战斗零落盘，finalize 恰好写一次 |
| 7 | 首进固定机关城 | totalRuns=0 时 1000 次必为机关城 |
| 8 | 隐藏技能唯一 + 刻印不可被顶 | 重复获得被拒、刻印槽拒绝局内技能 |
| 9 | 装备加成必须抬 D | 穿装备后战力与 D 同步上升 |

## 实现时对文档做的取舍

四处文档内部有冲突或缺口，实现时都作了明确取舍并在代码里就地注明，
汇总见仓库根目录 `重建说明.md`：

1. **敌人基准取哪张表** —— 红线 1 禁止逐位面强度表，故取平衡表三章的通用基准
   （小怪 20/3、精英 150/8、之主 300/12），五章的逐位面数值降级为设定参考。
   实测：这一改让 12 个位面的新手通关率从 0%~14.7% 收敛到 10.7%~17.7%。
2. **硬保底整层缺失** —— 整体策划 4.5 要求「PRD 递增」与「硬保底次数」两层并列，
   三套旧实现都只有第一层。已补上 `PITY_CAP`。
3. **基因→永久成长的换算率** —— 文档只给了「基因 ×5%」和「单局上限 +3%」，
   缺换算，取 600 基因/次（由文档自己的产出速率反推）。
4. **PRD 参数与稀有度目标数学上不可兼容** —— 唯一留给策划裁定的一条，
   `重建说明.md` 第四节第 4 条给了推导和三个可选方案。

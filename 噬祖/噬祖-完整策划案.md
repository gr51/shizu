## 1. 统一口径与冲突裁定

本章是合并时做出的权威裁定，开发和后续策划应按此执行。

### 1.1 副本阶段结构

统一为“5 个战斗阶段”：

| 阶段 | 内容 | 是否有精英/Boss | 主要作用 |
|---|---|---|---|
| 1 | 常规波次 | 无独立精英/Boss | 教学、热身 |
| 2 | 常规波次 | 无独立精英/Boss | 适应、建立操作节奏 |
| 3 | 常规波次 + 精英 | 有精英 | 引入压力与技能预警 |
| 4 | 复合波次 + 精英 | 有精英 | 形成 build 检验 |
| 5 | 位面之主战 | 有位面之主 | 通关、结算、剧情触发 |

原文中“每阶段带 Boss”“阶段 BOSS 击破”的说法统一解释为“阶段结束/精英击破后的结算节点”；阶段 1-2 不额外增加 Boss。升级触发使用“阶段结算 + 吞噬阈值”，避免和实现表中的 `stage 1-2 无 elite` 冲突。

### 1.2 诸天之心的出现方式

“诸天之心”保留为 12 个位面模板之一，进入随机池，不设置必须完成前 11 个位面才能出现的硬门槛。首次通关诸天之心时触发结局、解锁无尽模式并发放 1 个自选隐藏技能；它可以在较早阶段随机出现，但不保证早期出现。

这样同时保留：随机副本的核心承诺、结局内容、可重复挑战和无尽模式。

### 1.3 首次进入新位面的奖励通道

采用“先进入、后激活”的规则：

1. 首次进入某位面时，该局按未激活路线处理，三选一走属性通道。
2. 本局结算完成后激活对应路线，并处理永久互斥。
3. 之后再次进入该位面，才走匹配路线的技能通道。
4. 装备通道始终开放；不匹配位面装备掉率 ×1.5。

这条规则与 `generateDungeon()` 进入前判定通道、`finalizeRun()` 结算后激活路线的实现顺序一致。

### 1.4 路线互斥矩阵

| 已激活路线 | 永久封印 |
|---|---|
| 渡劫 / 功德 | 丧尸、共生 |
| 丧尸 / 共生 | 渡劫、功德 |
| 机甲 | 山海 |
| 山海 | 机甲 |
| 巨化 | 侠客 |
| 侠客 | 巨化 |
| 魔法、奇技 | 无，诡术组中立 |

互斥路线权重必须为 0；若配置错误仍抽中，必须重随机或替换到相容位面，不能只弹窗后继续生成冲突副本。

### 1.5 诸天之心的阶段例外

诸天之心仍遵循 5 个战斗阶段；第 5 阶段的位面之主“崩坏之影”内部包含 4 个形态/战斗阶段，结束后再播放结局演出。原表中的“4 阶段 Boss”指 Boss 内部形态，不是把整局缩成 4 个阶段。

### 1.6 每日挑战与排行榜

当前技术方案是纯前端 + 本地存档，因此只能保证固定种子在同一天可复现，不能保证真实的全服排行榜、反作弊或跨设备成绩同步。

- MVP：固定每日种子、本地成绩、分享截图/战绩文本。
- 后续若要全服排名：增加后端或平台云开发、账号标识、提交校验和反作弊方案。
- 在没有后端前，文案不得把“全服排名”写成已交付能力。

### 1.7 设计与实现红线

- 位面不设固有强度；敌人数值统一由 `基准 × D × 阶段系数 × dynFactor` 生成。
- `D` 在开副本时快照，局内成长不改变本局敌人数值。
- 不匹配位面三选一不得出现路线技能；装备仍可掉落。
- `dynFactor` 始终钳制在 `[0.70, 1.50]`。
- 跨局变更在结算流程集中写入，避免中途退出造成半存档。
- 隐藏技能唯一、永久、不可被普通局内技能替换。
- 装备战力必须进入 `computePower()`，并通过难度闭环消化。

### 1.8 合并后的已知待确认项

| 问题 | 影响 | 建议处理 |
|---|---|---|
| 团队规模、周期、预算未提供 | 无法锁定正式版内容量 | 先按小团队 First Playable / Vertical Slice 规划 |
| 广告、内购、平台 SDK 的当前权限与接入状态未知 | 影响商业化和上线排期 | 在可玩包后再接入，先验证核心循环 |
| `SkillSlotSystem` 中普通技能的局内装填与基因锁自动生效边界仍有实现细节 | 影响技能池是否为空、技能是否重复 | 以 `SKILL_REACH=2` 的最新修订实现并补回归测试 |
| 诸天之心早期随机出现时的剧情节奏 | 影响叙事顺序 | 采用碎片化叙事；首次通关才播放完整结局 |
| 无后端时的“全服排名” | 影响功能宣传 | MVP 暂不承诺，标记为 Parked |

## 2. Executive Summary

### 2.1 一句话定位

《噬祖》是一款竖屏单摇杆动作肉鸽：玩家操控巢灵穿行随机诸天位面，移动走位、自动索敌、吞噬基因、三选一进化，并在永久路线互斥与跨局成长中构筑自己的吞噬血脉。

### 2.2 玩家为什么反复玩

玩家每局重复做的不是“点击菜单”，而是：

1. 走位躲避敌人和 Boss 预警。
2. 追击并吸取基因，决定何时承担风险去捡资源。
3. 在属性通道、技能通道和装备掉落之间形成临时 build。
4. 观察随机位面和永久互斥，决定下一步血脉方向。
5. 把本局收益带回虫巢，继续挑战“差一点”的敌人。

### 2.3 当前建议

建议先批准“核心循环 First Playable”，而不是直接进入完整内容制作。第一阶段只证明：单摇杆移动、自动攻击、吞噬基因、5 阶段压力曲线、属性三选一和一次 Boss 技能预警是否成立。

### 2.4 最大风险

最大风险不是内容不足，而是系统过多导致短局体验失焦：移动、自动攻击、吞噬、三选一、技能槽、装备、互斥、传承、广告和剧情同时出现，可能让玩家无法理解“为什么我变强/为什么我失败”。

最小验证是一个单位面灰盒和 5 人测试，观察玩家是否能在首局完成核心行为、在第二局主动追求技能通道，并能说出失败原因。

| 维度 | 统一口径 | 来源标签 |
|---|---|---|
| 主品类 | 竖屏单摇杆动作 Roguelike + Roguelite | provided |
| 相邻体验 | 自动攻击、生存走位、局内构筑、跨局成长 | derived |
| 平台 | 微信小游戏、抖音小游戏 | provided |
| 单局时长 | 12-15 分钟 | provided / needs_research |
| 视觉方向 | 卡通 Q 版虫族、鲜艳主题位面 | provided |
| 差异化边界 | “吞噬基因 + 路线永久互斥 + 不匹配位面仍有装备收益”三者共同构成差异，不单独依赖题材 | derived |
| 商业模型 | 激励广告优先，外观/轻功能内购为假设 | assumption |

### 3.1 目标玩家

不是泛泛的“25-40 岁用户”，而是以下行为画像：

- 有碎片时间，愿意接受 12-15 分钟一局。
- 喜欢低操作门槛，但希望在走位、路线选择和局内 build 上保留决策感。
- 喜欢收集、成长和“下一局会更好”的反馈。
- 可以接受轻度随机，但拒绝“完全脸黑且没有保底”。
- 对连续失败可以接受，前提是永久财产不丢、失败原因可理解、下一局有明确目标。

### 3.2 玩家拒绝点

- 首局无法理解操作和成长因果。
- 小怪秒死、Boss 只会追撞，战斗没有节奏锚点。
- 广告打断关键战斗反馈或强迫观看。
- 永久互斥没有预警，导致玩家感觉被系统惩罚。
- 随机位面给不到任何有效收益。
- 数值膨胀让装备和升级只变成数字，没有视觉或行为变化。

## 4. Player Promise

| 层级 | 承诺 | 可观察行为 |
|---|---|---|
| 外部承诺 | 操控一只会吞噬诸天基因的巢灵，用每局进化和永久血脉选择活下来 | 玩家能在商店/宣传视频中看见移动、吞噬、进化、Boss 和路线变化 |
| 首 10 分钟 | 不需要复杂教程，也能学会移动、自动攻击、吸取、爆发和第一次三选一 | 首局完成关键行为；阶段 1-2 不弹复杂系统说明 |
| 长期承诺 | 每局带回永久属性、路线能力、传承或装备，路线互斥让账号形成不可复制的血脉档案 | 玩家会查看图鉴、追求相容位面、管理装备和隐藏技能 |

### 4.1 核心循环

```text
回巢查看成长
  -> 开裂缝，读取位面/路线/通道/风险回报
  -> 进入 5 阶段副本
  -> 移动走位 + 自动索敌攻击
  -> 击杀敌人，靠近吸取基因
  -> 阶段结算或吞噬阈值触发三选一
  -> 匹配位面选路线技能；不匹配位面选通用属性
  -> 装备从击杀掉落中独立获得
  -> 位面之主战 / 失败 / 结算
  -> 永久属性、路线、传承、装备、隐藏技能入库
  -> 难度根据战绩调整，回到下一局
```

### 4.2 资源与反馈闭环

| 输入 | 玩家行为 | 即时反馈 | 跨局结果 |
|---|---|---|---|
| 敌人、精英、Boss | 追击、攻击、躲避 | 命中特效、伤害数字、震屏、预警 | 基因、装备、传承 |
| 基因尸体 | 靠近吸取或长按爆发 | 吸取粒子、基因计数、回血/狂暴 | 永久属性转化、路线充能 |
| 三选一 | 比较属性/技能效果 | 卡片翻转、选中高亮 | 本局 build 改变 |
| 新位面 | 承担未知风险 | 位面主题、路线提示、互斥提示 | 激活路线或进入属性通道 |
| 结算 | 选择带回的收益 | S/A/B/C 评级、掉落揭示 | 账号战力、图鉴、装备库 |

## 5. 世界观与内容主线

### 5.1 世界观

太古之初，诸天本是一体。一场名为“大崩坏”的灾变撕裂世界，将其碎成无数位面，彼此之间只余残存的“裂缝”相通。裂缝中弥漫着崩坏之力，侵染万物，也催生变异。

噬祖是盘踞在虚空虫巢中的初代虫族母体，无法移动，以吞噬为生。它派出唯一的延伸——巢灵——穿行诸天位面，吞噬强者基因，以进化为躯壳、以吞噬对抗崩坏。

变强不是为了拯救世界，而是为了活下去并繁衍。

### 5.2 核心角色

| 角色 | 设计定位 | 表现规则 |
|---|---|---|
| 噬祖 | 母体、根源、回巢后的情绪锚点 | 声音低沉沙哑，短句，称巢灵为“孩子” |
| 巢灵 | 玩家唯一操作单位 | 无固定台词，以行动表达；可由玩家命名 |
| 崩坏之影 | 诸天贪欲和崩坏的具象化 | 使用所有位面强者的声音，作为最终 Boss |

### 5.3 叙事策略

- 副本随机，剧情不能依赖严格的关卡顺序。
- 开局对话在 2 秒内完成，不阻塞操作。
- 长文本只放入“传承残影”，作为可跳过、可回看的碎片叙事。
- 诸天之心首次通关播放完整结局；早期随机遇到时只给局部预兆。

### 5.4 故事阶段

| 阶段 | 体验重点 | 内容载体 |
|---|---|---|
| 起 | 苏醒、第一次吞噬、理解基本操作 | 机关城教学、噬祖短句 |
| 承 | 进入不同位面，感受路线差异和互斥 | 位面开场、路线激活、传承残影 |
| 转 | 发现崩坏真相，隐藏技能和装备成型 | 稀有传承、Boss 机制、图鉴 |
| 合 | 诸天之心决战，巢灵成为新的噬祖 | 结局演出、无尽模式 |

## 6. 核心玩法规格

### 6.1 操作

| 操作 | 手势/区域 | 规格 |
|---|---|---|
| 移动 | 左半屏虚拟摇杆 | 半径 60pt；全屏左 60%；响应目标 <50ms |
| 自动攻击 | 无操作 | 自动索敌最近敌人；目标切换 <100ms；攻击前摇 <80ms |
| 闪避翻滚 | 右半屏快速滑动 | 触发后 0.25s 无敌帧；第 2-3 局自然引入 |
| 吞噬爆发 | 右下 88×88pt 长按 | 长按 0.4s；范围吸取、回血、狂暴 3s；CD 30s |
| 暂停 | 右上 44×44pt | 可继续或回巢；回巢只结算已通关阶段收益 |

所有可点击区域至少 44×44pt；反馈延迟目标低于 50ms。

### 6.2 胜负和重试

| 项 | 规则 |
|---|---|
| 通关 | 完成 5 阶段并击杀位面之主 |
| 失败 | 巢灵生命归零；本局临时成长丢失 |
| 保留 | 已激活路线、永久属性、传承和已入库装备不丢失 |
| 广告复活 | 每局最多 1 次；半血 + 1.5s 无敌 |
| 中途退出 | 结算至已完成阶段，不视为完整通关 |

### 6.3 战斗串联规则

1. 阶段 1 小怪也需要 2-3 次基础攻击才能击杀，不能回到“一刀带走”。
2. 阶段 1-2 以波次和教学为主；阶段 3-4 引入精英及其技能；阶段 5 进入位面之主战。
3. 精英有 1 个简化技能，Boss 有 2-3 个技能循环。
4. 所有技能释放前至少 0.5s 预警（红圈、聚气、轨迹等）。
5. 阶段越深，敌人谱系和血量阶梯同时升级，而不是只提高数量。

### 6.4 三条成长通道

| 通道 | 触发 | 内容 | 跨局性 |
|---|---|---|---|
| 技能通道 | 匹配位面三选一 | 对应路线的基因锁技能；隐藏技能只在匹配位面/诸天之心出现 | 普通局内技能临时；隐藏技能永久刻印 |
| 属性通道 | 不匹配位面三选一 | 攻击、生命、速度、攻速、暴击、吸血、回血、射程等 | 本局强化；结算后部分转永久属性 |
| 装备通道 | 小怪/精英/Boss 掉落 | 6 槽装备、词条、合成、强化、分解 | 永久，参与战力计算 |

### 6.5 技能槽和隐藏技能

- 主动槽 2 格，被动槽 2 格。
- 基因锁的被动段自动生效，不占槽；主动段和局内主动技能进入主动槽。
- 槽满后新技能弹出“替换/放弃”；被替换普通技能销毁，不进入传承库。
- 隐藏技能会永久刻印一个槽位；被刻印槽位开局自动装载，不参与普通替换。
- 同一隐藏技能只能获得一次；诸天之心首通额外提供自选隐藏技能。

### 6.6 随机性控制

- 副本用 seed 生成，进入前生成位面、波次、通道和掉落规则。
- 已激活路线位面权重 ×2，未激活路线位面 ×1，互斥路线位面 ×0，诸天之心权重 1。
- 传承、传说技能、隐藏技能和装备各自维护 PRD 计数器。
- 连续失败会降低动态难度；通关会提高动态难度，始终钳制在 0.70-1.50。
- 每日挑战使用固定日期种子；没有后端时只承诺本地复现和分享，不承诺真实全服排名。

## 8. 跨局成长与装备

### 8.1 永久属性

局内吞噬基因的 5% 在结算时转化为永久成长；每次结算在攻击 +2%、生命 +2%、速度 +1% 中选择一项，单局三项合计上限 +3%，单维成长上限 +500%。

### 8.2 装备栏

| 槽位 | 名称 | 主属性倾向 |
|---|---|---|
| 1 | 噬爪 | 攻击 / 暴击 |
| 2 | 甲壳 | 生命 / 减伤 |
| 3 | 虫冠 | 攻击 / 技能冷却 |
| 4 | 足器 | 速度 / 闪避 |
| 5 | 基因核心 | 吸血 / 回血 |
| 6 | 传承饰品 | 混合词条 / 掉落加成 |

### 8.3 装备稀有度

| 稀有度 | 词条数 | 基础倍率 | 主要来源 |
|---|---:|---:|---|
| 普通 | 1 | 1.0 | 小怪、精英 |
| 精良 | 2 | 1.3 | 精英、阶段结算 |
| 稀有 | 3 | 1.6 | 位面之主保底 |
| 史诗 | 4 | 2.0 | 位面之主概率、合成 |
| 传说 | 5 | 2.5 | 位面之主低概率、合成 |

### 8.4 装备操作

- 合成：3 件同稀有度装备 -> 1 件高一档装备。
- 强化：同槽位同名装备 +3 件 -> +1 星；词条数值 ×1.1/星，上限 +5 星。
- 分解：白/绿/蓝/紫/金分别获得 1/3/8/20/50 装备精华；100 精华可换自选蓝装。
- 不匹配位面全部装备掉率 ×1.5；位面之主每局至少掉 1 件装备并保底稀有蓝。

## A. 战斗系统串联与验收

> 来源文件：噬祖-整体串联设计.md；以下为详细规格快照。
### 《噬祖》整体串联设计（战斗系统闭环）

> 版本 v1.0 · 目标是「一整局串起来」：阶段→敌人→血量→Boss 技能→玩家升级→永久成长，环环相扣，不是散装补丁。
> 参考：吸血鬼幸存者（敌人随时间变强 + 武器/被动双通道 + 数值爆炸曲线）、Hades（每关敌人谱系 + Boss 技能模式）。

---

#### 一、核心闭环（一局的骨架）

```
移动/走位 → 自动索敌攻击（武器弹体跟路线走）
  → 击杀敌人 → 掉基因 → 靠近吸取 → 基因充能
  → 局内「三选一」升级（属性通道 或 技能通道）
  → 变强 → 推进阶段（5 阶段）→ 敌人谱系+血量升级 → 精英/Boss 技能
  → 通关 → 永久基因锁解锁/升级（跨局成长）
```

**关键：玩家和敌人一起涨，谁也不许单边碾压。** 这是本次修正的核心。

---

#### 二、阶段 = 敌人谱系 + 血量阶梯（不是一刀带走）

| 阶段 | 场景 | 小怪 | 血量阶梯 | 精英/Boss |
|---|---|---|---|---|
| 1 | 酒馆街 | 毛贼、酒徒 | 弱（多刀才死） | 无 |
| 2 | 竹林 | 山贼刀手、镖师 | 中 | 无 |
| 3 | 擂台 | 拳师、棍僧 | 中强 | 精英·拳宗长老 |
| 4 | 江湖路 | 暗器贼、弓手 | 强 | 精英·暗器宗师 |
| 5 | 剑冢 | 悍匪、杀手 | 很强 | Boss·剑圣无名 |

**规则：**
1. 每阶段 2 种小怪（不同造型 + 不同武器），**血量逐阶段递增**，阶段 1 小怪也要「砍 2-3 刀」才死，不是秒杀。

#### 二、核心玩法设计

##### 2.1 玩法概述

玩家扮演**噬祖**（无法移动的虫巢母体）派出的**巢灵**（玩家唯一单位）。每次开局：开一道**诸天裂缝**，随机进入一个**位面副本**——副本从十方位面池中随机生成，**无穷无尽、没有终点**。副本内为 5 阶段连打（阶段 1-4 常规战 + 阶段 5 **位面之主**），单局 12-15 分钟。战斗中击杀敌人掉落**基因尸体**，靠近自动吸取基因。**技能/属性/装备三通道（核心规则）**：副本位面与已激活路线匹配 → 掉落该路线专属技能（基因锁分支）；不匹配 → 只能获得通用属性、学不到该位面的技能，**但依旧掉落装备**——装备是跨路线通用成长通道，**不匹配位面装备掉率 ×1.5** 补偿（进错位面也能带装备回家继续变强）。通关带回**属性加成 / 稀有传承 / 超低概率技能 / 装备**，回巢孵化强化，再开裂缝。

##### 2.2 核心循环

```
回巢强化（属性/传承/技能）
        ↓
  开裂缝（随机进入一个位面副本，无穷无尽）
        ↓
 首进位面 → 永久激活该路线基因锁（账号级）
        ↓
  单摇杆操控巢灵 → 副本内 5 阶段连打
        ↓
  吞噬基因 → 三选一（局内 Build）：
   匹配位面 = 路线专属技能（入技能槽位）｜ 不匹配位面 = 通用属性
        ↓
  第 5 阶段位面之主 → 结算
        ↓
  属性永久加成 + 传承 + 超低概率技能 + 装备 → 更强 → 循环
```

##### 2.3 操作方式（详细规格）

| 操作 | 手势 | 触发区域 | 响应要求 |
|---|---|---|---|
| 移动 | 左半屏虚拟摇杆（拖拽），摇杆半径 60pt | 全屏左 60% | 位移响应 <50ms，跟手 |
| 自动攻击 | 无需操作，索敌自动攻击最近敌人 | — | 索敌切换 <100ms，攻击前摇 <80ms |
| 闪避翻滚 | 右半屏滑动（任意方向快速滑动 8pt 内） | 全屏右 40% | 触发后 0.25s 无敌帧 |
| 吞噬爆发 | 长按吞噬键（屏幕右下，88×88pt） | 固定按钮 | 长按 0.4s 触发，范围吸取 + 回血 + 狂暴 3s |
| 暂停 | 右上角暂停键 44×44pt | 固定按钮 | — |

- 热区规范：所有可点击 UI ≥ 44×44pt；摇杆边缘 10pt 内滑动仍视为摇杆操作（防误触）
- 反馈延迟红线：任何操作反馈 <50ms

##### 2.4 胜负与重试

| 项 | 规则 |
|---|---|
| 过关条件 | 击杀阶段 BOSS（第 5 阶段 = 位面之主）即通过该阶段；打满 5 阶段且击杀位面之主 = 通关本次副本 |
| 失败条件 | 巢灵生命归零 = 本局失败（一命模式） |
| 失败惩罚 | 仅损失本局临时积累（局内基因锁进度、局内强化），**账号永久财产（已激活基因锁/永久属性/传承）不丢** |
| 重试机制 | 死亡后弹结算：看广告复活 1 次（复活后 1.5s 无敌 + 半血）；或直接结束本局回巢 |
| 中途退出 | 任意时刻可暂停退出，进度结算至已通关关卡（保留对应局内收益） |

#### 三、关卡设计总览

> 位面模板详细设计见《噬祖-关卡策划.md》。本章为概括性框架。

##### 3.1 副本结构与数量

- **副本无穷无尽**：每次开裂缝随机进入一个位面副本，副本池 = 12 个位面模板（机关城/奥法王国/奇巧迷宫/渡劫之域/功德圣境/尸海末世/共生巢/武侠江湖/山海洪荒/机甲战线/巨神界/诸天之心），**无新手/主路线/终章之分，全部平等随机**，**没有主线终点**，可无限挑战（图鉴收集是目标，不是通关线）。
- **每个副本内部 = 标准 5 阶段战斗**：阶段 1-4（常规战 + 阶段小 BOSS）→ 阶段 5（位面之主）。单局 12-15 分钟。
- **技能/属性/装备三通道（核心规则）**：副本位面路线 ∈ 已激活路线 → 三选一为路线专属技能；∉ 已激活路线 → 三选一为通用属性（无技能）。首进新位面激活对应路线后，该位面即进入"技能通道"。**装备通道对全部位面开放**：无论匹配与否，位面之主与精英/小怪都可掉落装备，不匹配位面装备掉率 ×1.5——保证"进错位面也能带装备回家继续成长"。

##### 3.2 难度曲线设计（副本难度随玩家战力同步进化）

**核心公式（难度进化）**：
```
副本难度值 D = 玩家当前战力 × 难度等级系数
难度等级系数：简单 0.9 ｜ 中等 1.5 ｜ 困难 2.0
例：战力 1 → 简单 0.9 / 中等 1.5 / 困难 2.0
    战力 100 → 简单 90 / 中等 150 / 困难 200
（副本内所有敌人数值 = D × 阶段系数，位面模板不设固有难度）
```

**动态调节**（每次副本结束后调整难度等级系数）：
```
通关 → 下次副本难度 +5%~+15%（难度系数累乘）
连续失败 2-3 次 → 难度 -5%~-10%
难度系数钳制范围：0.70 ~ 1.50
```

**变量递增顺序**（每次只加一个维度）：数量 → 速度 → 复杂度 → 精度。

**单局内节奏（5 阶段）**：

| 阶段 | 时间 | 定位 | 敌人强度 |
|---|---|---|---|
| 1 | 0-2min | 教学/热身 | D × 0.9 |
| 2 | 2-5min | 适应 | D × 1.0 |
| 3 | 5-8min | 挑战（精英夹击） | D × 1.15 |
| 4 | 8-11min | 极限（复合敌群） | D × 1.3 |
| 5 | 11-15min | 位面之主 BOSS 战 | D × (1.10 ~ 1.15)（随机，锁定"差一点"） |

##### 3.3 新机制引入节奏（概括）

#### 四、游戏机制详解

##### 4.1 基因锁系统（核心机制）

**结构**：
- 10 条路线分 5 组（每组 2 条）：仙途（渡劫/功德）、武炼（侠客/山海）、诡术（魔法/奇技）、钢铁（机甲/巨化）、异变（丧尸/共生）
- 每条路线 = 6 段基因锁（Lv1-6），每段解锁一个专属能力，第 6 段 = 路线终极技

**激活规则**：
- 首次进入某位面副本 → 永久激活该路线基因锁（账号级，跨局累积）
- 组内两条可同时激活 = 双路线（两套基因锁并行解锁，能力混合）
- 终局可集齐 10 条（图鉴向）

**技能/属性/装备三通道（成长获取硬规则）**：
- 副本位面路线 ∈ 已激活路线 → 三选一升级池为**该路线基因锁分支技能**，掉落物含路线专属技能（含隐藏技能）
- 副本位面路线 ∉ 已激活路线 → 三选一升级池为**通用属性**（攻/血/速/暴击/回血等），掉落物只有属性基因，**不产出任何路线技能**；但**装备掉率 ×1.5 补偿**
- 装备通道全位面开放：无论匹配与否都能掉落装备（见 4.7 装备栏系统），装备是跨路线通用成长通道
- 含义：想学山海的本事，就得激活山海路线、进山海位面；进丧尸位面只能"长肉"（属性），学不会丧尸的活计——但**照样能捡到装备**，进错位面也有收获。

**互斥规则（永久互斥）**：

```
仙途组(渡劫/功德)  ⇆  异变组(丧尸/共生)   4 对全互斥
钢铁组(机甲/巨化)  ⇆  武炼组(侠客/山海)   机甲↔山海、巨化↔侠客 互斥
诡术组(魔法/奇技)  ——  中立，可与任何非对立路线组合
```

- 永久互斥：激活渡劫后，丧尸/共生永远无法激活；图鉴显示"已封印 · 你的血脉拒绝了它"
- **无重置机制**：一条账号一路走到黑（宿命感 = 留存钩子）
- **首次教学**：首次副本固定为机关城（完成移动/索敌/吸基因教学），此后全部随机

**基因锁能力示例**（每条路线 6 段，完整表见关卡策划/数值章节）：

| 路线 | Lv1 | Lv3 | Lv5 | Lv6 终极技 |
|---|---|---|---|---|
| 渡劫 | 攻击附带小雷击 | 雷链弹射 2 目标 | 天雷护体反伤 | 「九重雷劫」全屏落雷 |
| 功德 | 击杀回血 | 金身减伤 15% | 业力反伤 | 「金身不灭」3s 无敌 |
| 丧尸 | 吸血 5% | 死亡敌人尸爆 | 尸潮召唤 | 「尸山血海」召尸潮 |
| 共生 | 吸取敌方攻速 | 寄生小怪反水 | 母体分裂 | 「共生体」双核心 |
| 侠客 | 暴击 +5% | 连招强化 | 剑气外放 | 「万剑归宗」剑气风暴 |
| 山海 | 体型 +10% | 践踏 AOE | 兽魂附体 | 「饕餮巨口」吞噬一切 |
| 魔法 | 弹幕 +1 | 元素附加 | 法力涌动 | 「禁咒」全屏奥术 |
| 奇技 | 机关召唤 | 陷阱强化 | 傀儡分身 | 「天工开物」机关大军 |
| 机甲 | 远程速射 | 护盾充能 | 导弹齐射 | 「高达合体」巨型机甲 |
| 巨化 | 攻击范围 +20% | 震地击 | 体型巨化 | 「顶天立地」巨神形态 |

##### 4.2 战斗机制（核心机制）

- **自动索敌**：巢灵自动攻击最近敌人，可被三选一升级强化（攻击模式/范围/弹道）
- **吞噬**：敌人死亡掉落基因尸体，靠近自动吸取（吸取半径 40pt，吸取动画 200ms）；长按吞噬键 = 范围爆发（吸取周围所有尸体 + 回血 + 狂暴 3s，CD 30s）
- **闪避翻滚**：0.25s 无敌帧，可穿怪
- **精英夹击**：第 3 阶段起精英怪会绕过战线直扑巢灵（偷家机制），制造攻防压力
- **位面主题机制**：每位面有专属战场机制（如渡劫位面随机落雷、机甲位面炮台阵列、丧尸位面尸爆连锁）

##### 4.3 局内 Build（三选一升级）

- 触发时机：每阶段 BOSS 击破后 + 累积吞噬达阈值（每副本 1-2 次）
- 选项来源（技能/属性双通道；装备为第三通道，不走三选一，走击杀掉落）：
  - 匹配位面（路线已激活）→ 三选一 = 该路线基因锁分支技能（2-3 个选项随机）
  - 不匹配位面（路线未激活）→ 三选一 = 通用属性强化（攻击/生命/速度/暴击/吸血等），**不出现任何路线技能**
- 稀有度分布：基础 40% / 特色 40% / 稀有 15% / 传说 5%（传说 = 路线特有超低概率，仅匹配位面产出，改变玩法）
- **技能槽位**：局内获得的主动技能/召唤类技能装入**主动槽**（默认 2 格），被动强化装入**被动槽**（默认 2 格）；槽位满后获得新技能 → 弹窗选择替换（被替换技能销毁）；基因锁被动段（Lv1/3/5）自动生效**不占槽**，仅主动段（Lv5 召唤类、Lv6 终极技）占主动槽。详见 4.6。
- 升级间隔：首次升级 30-60s，之后每 60-90s，单局总计 6-12 次

##### 4.4 跨局成长（Roguelite 留存）

| 系统 | 说明 | 获取方式 |
|---|---|---|
| 永久属性 | 攻/血/速按比例永久加成 | 吞噬基因按比例结算留存（局内吞噬量的 5% 转化为永久属性点） |
| 稀有传承 | 保底掉落，自带"位面残影"短文（碎片叙事） | 保底 = 1/基础概率 × 1.5-2；如概率 5% → 30-40 次内必出 |
| 超低概率技能 | 分支专属，第 6 段终极技外的稀有变体 | PRD 伪随机保护，连续不触发概率递增 |
| 装备 | 跨路线通用词条（攻/血/速/暴击/减伤等） | 任意位面掉落（不匹配位面 ×1.5），词条按价值折算进战力 |
| 基因锁 | 路线能力树（上文 4.1） | 首进位面激活 + 局内充能 |

##### 4.5 随机性控制

- **输入随机为主**：副本布局/敌人/路线基因在进入前生成，玩家看到结果再决策
- **PRD 伪随机**：传承/稀有技能掉落连续不触发则概率递增，消除极端脸黑
- **保底机制**：传承保底次数 = 1/概率 × 1.5-2
- **每日挑战固定种子**：全服同副本布局，分数可比 + 可分享

##### 4.6 技能槽位与隐藏技能

**技能槽位（局内 Build 载体）**：

| 槽位 | 数量 | 装载内容 | 规则 |
|---|---|---|---|
| 主动槽 | 2 | 主动技能（终极技/召唤/爆发类） | 基因锁主动段与局内三选一主动技能入此槽 |
| 被动槽 | 2 | 被动强化（增伤/回血/攻速等） | 局内三选一被动强化入此槽 |
| 基因锁被动段 | — | Lv1/3/5 被动能力 | 自动生效，不占槽位 |

- 槽位满后获得新技能 → 弹窗列出"替换哪个槽位 / 放弃新技能"；被替换技能销毁，不入传承库
- 同一技能不可重复装载；换出后未学的技能保留在"待选池"中，后续三选一仍可能再次出现

**隐藏技能（禁忌级，稀有度高于传说）**：

- 稀有度：隐藏（Hidden）> 传说（Legendary），**获得后永久替换某一个技能槽位**——该槽位局局开局即带此技能，**跨局永久生效**
- 获得方式：仅匹配位面掉落（隐藏技能必属某路线），PRD 伪随机保护；基础概率 0.1%（传说之上）；首通诸天之心必得 1 个自选
- 作用：**永久替换技能槽位**——获得隐藏技能时选择一个空槽或已有技能的槽位，将该槽位永久锁定为该隐藏技能；此后该槽位不再参与局内替换/三选一，开局自动装备
- 上限：每槽位最多 1 个隐藏技能；4 个槽位全部刻印隐藏技能 = 大成就（诸天共鸣）
- 不可出售/不可丢弃/不可重复获得同一隐藏技能；图鉴新增"禁忌"稀有度栏

##### 4.7 装备栏系统（跨路线通用成长）

**定位**：装备是唯一不依赖路线激活的成长通道。**任何位面都掉装备**，不匹配位面（属性通道）装备掉率 ×1.5——解决"进错位面学不到技能"的挫败感，任何副本都能"带装备回家"。

**装备栏结构（6 槽位）**：

| 槽位 | 名称 | 主属性倾向 |
|---|---|---|
| 1 | 噬爪 | 攻击 / 暴击 |
| 2 | 甲壳 | 生命 / 减伤 |
| 3 | 虫冠 | 攻击 / 技能冷却 |
| 4 | 足器 | 速度 / 闪避 |
| 5 | 基因核心 | 吸血 / 回血 |
| 6 | 传承饰品 | 混合词条 / 掉落加成 |

**装备稀有度与词条**：

| 稀有度 | 词条数 | 基础数值倍率 | 掉落来源 |
|---|---|---|---|
| 普通（白） | 1 | 1.0 | 任意位面小怪/精英 |
| 精良（绿） | 2 | 1.3 | 精英 / 阶段 BOSS |
| 稀有（蓝） | 3 | 1.6 | 位面之主保底 |
| 史诗（紫） | 4 | 2.0 | 位面之主概率 |
| 传说（金） | 5 | 2.5 | 位面之主低概率 + 合成 |

- 词条池：攻击+X% / 生命+X% / 速度+X% / 暴击+X% / 攻速+X% / 吸血+X% / 减伤+X% / 回血+X%/s / 技能冷却-X% / 吸取半径+X%
- 词条按价值折算进战力（见 5.1 公式），装备越强 → 战力越高 → 副本难度 D 同步进化，数值闭环不失控

**装备获取与强化**：

| 途径 | 说明 |
|---|---|
| 位面掉落 | 任意位面：小怪 0.5% / 精英 4% / 阶段 BOSS 8% / 位面之主 100%（保底稀有蓝） |
| 不匹配位面 | 装备掉率 ×1.5（属性通道补偿） |
| 合成 | 3 件同稀有度任意装备 → 1 件更高稀有度（白→绿→蓝→紫→金） |
| 强化 | 同槽位同名装备 +3 件 → 该装备 +1 星（词条数值 ×1.1/星，上限 +5 星） |
| 分解 | 多余装备分解为"装备精华"，用于合成保底 |

**与双通道的关系（核心规则补充）**：技能通道 = 匹配位面专属；属性通道 = 不匹配位面专属；装备通道 = 全位面共享。三者叠加构成完整收益预期，位面卡展示"可获奖励：技能/属性/装备"。

##### 5.1 核心数值公式

```
巢灵战力 = 基础属性(攻/血/速) × 永久加成系数 × 基因锁加成 × 装备加成
装备加成 = 1 + Σ(已装备词条价值折算)（词条按攻/血/速等值折算，公式见《噬祖-数值平衡表.md》）
副本难度值 D = 巢灵战力 × 难度等级系数（简单 0.9 / 中等 1.5 / 困难 2.0）
敌人战力 = D × 阶段系数 × 动态难度系数
阶段系数（5 阶段）：0.9 / 1.0 / 1.15 / 1.3 / BOSS 公式
BOSS 公式：BOSS 战力 = D × (1.10 ~ 1.15)
单次伤害 = 攻击力 × 技能倍率 × 暴击(1.5×) − 目标防御(若有)
```

##### 5.2 基因经济（局内）

| 参数 | 数值 |
|---|---|
| 基因产出速率 | 40-60 基因/分钟 |
| 小怪掉落 | 5-10 基因 |
| 精英掉落 | 30-50 基因 |
| 阶段 BOSS 掉落 | 80-120 基因 |
| 位面之主掉落 | 200-300 基因 + 传承碎片 |
| 一次升级所需 | 局内递增：80 → 120 → 170 → 230 → 300 … |

##### 5.3 永久属性转化

```
局内吞噬基因总量 → 结算转化：攻 +2% / 血 +2% / 速 +1%（每次结算，三选一属性）
单局上限：三种属性合计 +3%
```

##### 5.4 传承掉落

| 稀有度 | 基础概率 | 保底次数 |
|---|---|---|
| 普通传承 | 20% | 8 次内必出 |
| 稀有传承 | 5% | 30-40 次 |
| 超低概率技能 | 0.5% | PRD 递增（300 次内期望 1-2 个） |
| 隐藏技能（禁忌级） | 0.1%（匹配位面专属，槽位永久替换） | PRD 递增（500 次内期望 1 个） |
| 装备 | 见 4.7（位面之主 100% 保底稀有） | 位面之主每局必掉 |

##### 5.5 成长天花板与数值膨胀控制

- 每次升级数值提升 ≥10%（可感知）
- 副本难度随玩家战力同步进化（难度等级系数天然满足），设置战力上限（单维成长上限 500%）
- 数值表逐位面详见《噬祖-关卡策划.md》数值详表


#### 九、技术实现要点

##### 9.1 推荐技术栈

- Cocos Creator 3.x（TypeScript）
- 微信小游戏 SDK + 抖音小游戏 SDK（适配层封装，双端一套代码）
- 本地存档：`localStorage` / 微信 `wx.setStorage` 封装
- 无后端；每日挑战种子用固定数值种子 + 本地时间对齐

##### 9.2 核心算法/逻辑

| 模块 | 实现要点 |
|---|---|
| 副本随机生成 | 种子随机（进局固定 seed）：位面池抽取（权重：已激活路线×2 / 未激活×1 / 互斥×0）→ 位面主题 → 地图布局 → 敌人波次表 → 技能/属性通道标记 |
| 自动索敌 | 每帧扫描半径内最近敌人，目标切换 100ms 冷却；攻击前摇可打断 |
| 难度进化 | 难度等级系数持久化在存档；副本难度值 = 玩家当前战力 × 等级系数，通关/失败后按 5.1 公式调整 |
| 基因锁系统 | 配置表驱动（10 路线 × 6 段能力，JSON）；激活/互斥用状态位图 + 互斥规则表 |
| 三选一 Build | 从当前路线能力池按稀有度权重随机 3 个，去重；主动技能入主动槽、被动强化入被动槽，槽满触发替换 |
| 技能槽位与隐藏技能 | 槽位状态存档持久化；隐藏技能 = 槽位永久刻印标记，开局自动装载，不参与局内替换 |
| 装备掉落与合成 | 位面掉落权重（不匹配 ×1.5）→ 装备对象（6 槽位 × 5 稀有度 × 词条 roll）→ 合成 3→1 / 强化 +1 星 / 分解精华 |
| PRD 保底 | 每类掉落独立计数器（传承/技能/装备/隐藏技能），未触发则概率递增 |
| 吞噬系统 | 尸体对象池；吸取 = 圆形检测 + 缓动回收 + 飘字 |
| 震动手感 | 微信/抖音振动 API 封装 + 视觉抖动降级 |

##### 9.3 性能优化

- 敌人/尸体/飘字全部对象池化，同屏上限 60 单位
- 卡通 Q 版素材压缩：纹理 ≤ 1024，图集合并
- 双端启动体积目标 ≤ 4MB（首包），资源分包加载
- 特效粒子 LOD：低端机降粒子数，保留核心反馈

##### 9.4 适配说明

- 竖屏安全区适配（刘海屏 `safe-area`）
- 摇杆热区随分辨率缩放，最小可点区 44×44pt
- 双端分享卡片、激励视频广告位（复活/双倍奖励）统一封装

## C. 关卡策划详细规格

> 来源文件：噬祖-关卡策划.md；以下为详细规格快照。
### 《噬祖》关卡策划

> 版本：v1.2（阶段三 · 策划实现，副本随机化 + 难度进化修订）
> 文档定位：12 个位面副本模板逐模板详细设计 + 难度公式与数值基准 + 机制引入节奏表 + 随机调度规则。AI 读完可直接实现副本生成与每个位面的具体逻辑。

#### 一、副本总览

##### 1.1 副本结构与数量

- **副本无穷无尽**：副本池 = 12 个位面模板（机关城/奥法王国/奇巧迷宫/渡劫之域/功德圣境/尸海末世/共生巢/武侠江湖/山海洪荒/机甲战线/巨神界/诸天之心），**无新手/主路线/终章之分，全部平等随机**，**没有主线终点**。每次开裂缝随机进入一个位面副本，可无限挑战（图鉴收集是长线目标）。
- **每个副本内部 = 5 阶段连打**（对应玩家确认的"单局 5 阶段各带 BOSS"）：阶段 1-4 为常规战（各带小 BOSS），阶段 5 为**位面之主**大 BOSS。单局 12-15 分钟。
- **诸天之心**为 12 位面模板之一（全路线融合位面，剧情收束），随机可遇、可重复挑战，无特殊解锁条件。

##### 1.2 难度曲线（副本难度 = 玩家战力 × 等级系数）

```
副本难度值 D = 玩家当前战力 × 难度等级系数
难度等级系数：简单 0.9 ｜ 中等 1.5 ｜ 困难 2.0
例：战力 1 → 简单 0.9 / 中等 1.5 / 困难 2.0
    战力 100 → 简单 90 / 中等 150 / 困难 200
动态难度在此基础上按整体策划 5.1 公式浮动（0.70~1.50 钳制）
```

> ⚠️ **重要说明（避免编码误解）**：位面模板**不设固有强度系数**——所有位面的敌人数值统一由"玩家当前战力 × 难度等级系数"生成，副本难度随玩家进化同步进化。位面之间的差异 = 敌人类型/机制/路线基因，而非数值高低。下表 01-12 为**位面图鉴顺序**（收集展示用），**不是游玩顺序**，12 个位面平等随机（权重见第五节）。

##### 1.3 阶段划分

| 阶段 | 定位 | 说明 |
|---|---|---|
| 入门期 | 第 1-3 次副本 | 教学做中学（首次固定机关城），机制逐步开放 |

#### 二、位面模板详细设计（副本池内容）

> 以下 12 个位面是**副本池模板**，每次开裂缝随机抽取其一生成副本。每个模板内标注「技能通道/属性通道」：该位面路线已激活 → 技能通道；未激活 → 属性通道（具体规则见第五节规则 4）。
> 模板内 HP/攻击数值均为**玩家战力 1 时的基准参考**，实际对局数值统一按第三章公式：实际值 = 基准 × 副本难度值 D × 阶段系数（差异化体现在敌人类型与机制，数值不因位面而异）。

##### 位面模板 01 · 机关城（奇技路线）

- **副本目标**：通过 5 阶段，击杀位面之主「傀儡巨像」
- **新引入元素**：移动摇杆 / 自动索敌攻击 / 靠近尸体吸取基因 / 吞噬爆发键（长按）
- **路线基因**：首进激活「奇技」基因锁（诡术组，中立可组合）
- **5 阶段配置**：
  - 阶段1「齿轮长廊」：3 波机关鼠小怪（HP 20，攻击 3）
  - 阶段2「齿轮走廊」：4 波机关鼠 + 1 波齿轮飞轮（HP 25，攻击 4）
  - 阶段3「轴承大厅」：3 波齿轮飞轮 + 精英「发条守卫」（HP 150，攻击 8，冲撞技）
  - 阶段4「机芯回廊」：4 波混合 + 精英「发条守卫×2」
  - 阶段5「傀儡之主」：位面之主「傀儡巨像」（HP 300，攻击 12，三阶段：本体 → 部件飞出 → 狂暴）
- **剧情触发点**：进入关卡触发开场（噬祖醒来，首次裂缝）；首杀位面之主触发传承提示
- **预期玩家体验**：30 秒内理解"移动+索敌+吸基因"三件事；第一只小 BOSS 险胜，心跳初体验；通关后"原来我能变强"的正反馈

- **5 阶段配置**：

  - 阶段2「元素回廊」：4 波火/冰元素（HP 30，攻击 5，火球/冰锥弹道）
  - 阶段3「图书馆」：3 波 + 精英「元素导师」（HP 180，攻击 9，三连火球）

- **剧情触发点**：开场介绍"十方位面"概念；击杀秘法王触发第一条传承残影
- **预期玩家体验**：学会躲避弹幕；第一次三选一升级的抉择感；双路线组合初现端倪

1. **裂缝随机生成**：每次开裂缝按位面池权重随机抽取副本（权重见 1.2 表与整体策划 3.4：已激活路线位面 ×2 / 未激活位面 ×1 / 互斥位面 ×0）；全部激活后全池随机（重复挑战拿传承/材料）。**12 个位面无新手/终章之分，全部进入同一随机池**
2. **互斥冲突兜底**：若随机到与已激活路线互斥的位面（如已激活渡劫却随机到尸海末世）→ 不生成该位面，替换为同组相容位面或重随机
3. **首次教学**：首次副本固定为机关城（完成移动/索敌/吸基因教学），此后全部随机
4. **技能/属性/装备三通道（硬规则，编码必须实现）**：
   - **匹配位面**（该位面路线 ∈ 已激活路线）→ 三选一升级池 = 该路线基因锁分支技能；掉落物含路线专属技能 + 隐藏技能（禁忌级 0.1% PRD）
   - **不匹配位面**（该位面路线 ∉ 已激活路线）→ 三选一升级池 = 通用属性（攻/血/速/暴击/吸血等）；**不产出任何路线技能**，只掉属性基因；**装备掉率 ×1.5 补偿**
   - **装备通道全位面开放**：无论匹配与否，小怪/精英/阶段 BOSS/位面之主都可掉落装备（见数值平衡表 7.5）；位面之主 100% 保底
   - 首进新位面激活该路线后，该位面从"属性通道"转为"技能通道"（跨局生效）；装备通道不变

> **⚠ 2026-08-21 修订 · 技能通道给哪些段位**
>
> 原文写的是「三选一只给**已解锁段位**」。但基因锁的实现是「已解锁段位**开局自动生效**」
> （见 `core/run.js` 的策划裁定：基因锁不占技能槽，解锁后自动生效），
> 两条规则用的是同一个谓词 `skill.lv <= geneLocks[route]` ——
> 前者先把这批技能全发了，后者再排除「已学过的」，**技能池因此恒为空集**。
> 实测连打 8 局、59 次三选一、177 个选项，技能类一个都没出现：
> `data/skills.js` 里的 60 个技能是彻底的死内容，而全套单测照样绿灯
> （因为测试传的是空 `learnedSkills`，那个状态在真实游戏里不存在）。
>
> 现改为：**三选一提供「已解锁段位之上、`SKILL_REACH`（=2）段以内」的段位**。
> 定位区分为 —— 基因锁 = 跨局永久解锁；三选一 = 本局提前够到下一段，打完不保留。
> 这样既让技能内容真正进池，也保留原意里「不许一步够到终极技」的节奏约束。
> 对应实现 `core/upgrade.js: skillPool()`，回归测试见
> `tests/channels.test.mjs`「模拟开局自动发放后，技能池仍然出得来货」。

| 分解 | 白 1 / 绿 3 / 蓝 8 / 紫 20 / 金 50 装备精华；精华用于合成保底（100 精华 = 自选蓝） |

---

#### 八、成长曲线（参考）

> 基准：每次通关结算战力 ≈ 增长 1.67%（攻+2%/血+2%/速+1% 三选一轮转，折算战力 ×(1.02+1.02+1.01)/3）。以下为纯结算成长的理论估算，实机以留存数据调参。

| 阶段 | 战力区间 | 大约所需结算次数 | 玩法内容 |
|---|---|---|---|
| 新手期 | 1 → 3 | ~66 次 | 首次固定机关城 → 全随机；激活首路线 |
| 成长期 | 3 → 10 | ~73 次 | 第二路线激活、互斥抉择、传承收集 |
| 高潮期 | 10 → 50 | ~97 次 | 双路线成型、组合技、高难位面 |
| 收束期 | 50 → 100 | ~42 次 | 首通诸天之心、结局演出、无尽模式 |
| 长线 | 100 → 500 | ~97 次 | 全收集、传承补齐、周活/赛季 |
| 天花板 | 500 → 1000 | ~42 次 | 接近单维 500% 上限，数值收敛 |

**基因锁战力加成**（开发实现指南 `geneLockPowerBonus` 引用）：每段基因锁 +2% 战力（平衡参考），单路线满 6 段 +12%；双路线满解锁共 +24%。加成在战力折算公式中相乘。

**装备战力加成**（开发实现指南 `gearPowerBonus` 引用）：`装备加成 = 1 + Σ(词条数 × 基础倍率 × 2.5%)`。装备是唯一不依赖路线的成长通道，**任意位面掉落**（不匹配位面 ×1.5）——战力 1 起步时无装备（加成 1），新手期装备主要来自位面之主保底蓝（≈ +12%），长线全传说 6 槽 ≈ +187.5%。装备加成与永久属性、基因锁加成三者相乘，共同驱动副本难度 D 同步进化。

**数值膨胀控制**：战力每提升一档，副本 D 等比提升 → 敌人随玩家同步进化，玩家体验始终"差一点"；永久加成单维封顶 +500%，避免无限膨胀。

#### 一、世界观设定

##### 1.1 世界观概述

太古之初，诸天本是一体。一场名为「大崩坏」的灾变撕裂了世界，将其碎成无数位面，彼此之间只余残存的「裂缝」相通。裂缝中弥漫着崩坏之力，侵染万物，也催生变异。当世仅存一位古老存在——**噬祖**，一只盘踞在虚空虫巢中的母体，无法移动，以吞噬为生的初代虫族之祖。噬祖派出它唯一的延伸——**巢灵**，穿行诸天位面，吞噬一切强者的基因，以进化为躯壳、以吞噬对抗崩坏。

变强不是为了拯救世界，是为了**活下去并繁衍**。

##### 1.2 核心设定

| 设定 | 说明 |
|---|---|
| 噬祖 | 无法移动的虫巢母体；动机=族群延续；缺陷=失去巢灵则孤独消亡；关系=母体/根源 |
| 巢灵 | 玩家唯一单位；动机=吞噬变强、探索未知位面；缺陷=死亡即本局结束；关系=噬祖的延伸与唯一希望 |
| 基因 | 一切强者的力量结晶，可被吞噬并永久强化；吞噬行为即故事 |
| 裂缝 | 连接诸天位面的残存通道；每道裂缝随机通向一个位面 |
| 基因锁 | 位面强者血脉中埋藏的进化密码；吞噬其基因即可逐段解锁 |
| 传承 | 位面强者的意志碎片；吞噬时浮现「位面残影」短文 |
| 崩坏 | 侵蚀诸天的灾变力量；最终 BOSS「崩坏之影」是其化身 |

##### 1.3 角色设定

- **噬祖**（母体）：声音低沉沙哑，话语简短如兽。称呼巢灵为"孩子"。
- **巢灵**（主角/玩家）：沉默的猎手，无台词，靠行动表达；有初始可选名字（玩家起名）。
- **崩坏之影**（最终 BOSS）：诸天崩坏的具象化，会用所有位面强者的声音说话。

#### 二、故事主线

##### 2.1 故事梗概（300 字）

诸天崩坏，位面割裂。噬祖从沉睡中醒来，派出巢灵穿过第一道裂缝——机关城。巢灵吞噬机械生物，首次解锁基因锁，明白了自己的使命：吃下一切，变得更强。此后每道裂缝都是一场未知——渡劫之域的天雷、功德圣境的金身、尸海末世的尸潮、共生巢的寄生、武侠江湖的剑气、山海洪荒的凶兽、机甲战线的钢铁、巨神界的巨人——每吞下一个位面的强者，就离真相更近一步：崩坏并非天灾，而是诸天强者贪欲吞噬彼此而生的恶果。它只学得会自己血脉承认的本事，异族基因只能化作肉身之养。最终，巢灵抵达诸天之心，直面崩坏之影。决战中，巢灵释放自己吞噬的一切基因，将崩坏之影反噬吞噬。诸天裂缝闭合，万界重归完整。噬祖轻声说："孩子，你终于……成为新的噬祖了。"巢灵回到虫巢，一切开始的地方，也是新的开始。

##### 2.2 故事结构（起承转合）

| 环节 | 进度节点 | 内容 |
|---|---|---|
| 起 | 第 1-3 次副本 | 巢灵苏醒，初入位面，学会吞噬与进化 |
| 承 | 第 4-7 次副本 | 穿越仙途与异变位面，体验路线抉择与血脉冲突；首次拾得装备（跨路线通用成长） |
| 转 | 第 8-11 次副本 | 窥见崩坏真相，位面越强，腐化越深；技能槽位成型、禁忌级隐藏技能渐次觉醒 |
| 合 | 诸天之心位面 | 决战崩坏之影，吞噬崩坏，诸天归一，巢灵成新噬祖 |

##### 2.3 情感曲线

```
起点(迷茫) → 第1-3次副本(新奇/成就) → 第4-7次副本(抉择/沉重)
→ 第8-11次副本(震撼/宿命) → 诸天之心位面(热血/感动/圆满)
```

#### 三、位面副本剧情模板（12 模板随副本随机触发）

> 叙事原则：碎片化叙事，叙事不打断操作。开局即战，对话框极简；传承残影为唯一长篇文本载体。副本随机生成，进入哪个位面即触发对应模板；模板间的对话不依赖固定顺序，任何顺序都成立。

##### 位面模板 01 · 机关城

- **剧情背景/触发条件**：首次进入游戏，噬祖苏醒
- **开场对话**（进入关卡的 2 秒内，底部一句话，不阻塞操作）：
  - 噬祖："……醒了。诸天，碎成什么样了？去，看看外面。"
- **过关后剧情推进**：巢灵击杀傀儡巨像，吞噬其核心，体内首次浮现一道基因锁。
- **过关对话**：
  - 噬祖："机械……也能吃出基因。有意思。孩子，记住——吃，是活着的道理。"
  - （传承提示弹出）：传承「机关残影」——"我是第一个被造出的傀儡，我的造物主说：你比人更像人。我信了，直到他把我拆了，装进第二十七个我。"

##### 位面模板 02 · 奥法王国

- **剧情背景/触发条件**：第二道裂缝开启
- **开场对话**：
  - 噬祖："法术？花里胡哨。去吧，嚼碎了就知道它是什么味道。"
- **过关后剧情推进**：巢灵首次通过三选一解锁基因锁分支，理解"进化可以由自己选择"。
- **过关对话**：
  - 噬祖："十方位面，十个样子。吃法，也各不相同。你自己挑。"
  - （传承提示）：传承「秘法残影」——"我的老师临终说，魔法的尽头是知识。我翻遍全书才明白，知识的尽头是遗忘。我忘了怎么回家。"

##### 位面模板 03 · 奇巧迷宫

- **剧情背景/触发条件**：前三次探索收尾（副本随机，遇到即可触发）
- **开场对话**：
  - 噬祖："前头是三岔口。往哪边，都行。反正……都是吃。"
- **过关后剧情推进**：三次探索已过，诸天之门对巢灵完全敞开，后续裂缝全随机。
- **过关对话**：
  - 噬祖："诸天之门，为你敞开了。去吧，孩子，吃遍十方。"

##### 位面模板 04 · 渡劫之域

- **剧情背景/触发条件**：进入仙途组位面；激活渡劫路线 → 永久封印异变组
- **开场对话**：
  - 噬祖："雷？这东西劈开过我的先辈。小心点，孩子。……对了，吃了它，你体内那些脏东西，就再也进不来了。"（暗指永久互斥）
- **过关后剧情推进**：巢灵血脉染上雷光；图鉴显示异变组「已封印 · 你的血脉拒绝了它」。
- **过关对话**：
  - 噬祖："很好。有些门，走进去，别的门就关了。这就是选择的分量。"
  - （传承提示）：传承「雷劫残影」——"我在天劫下活了九十九次。第一百次，我低头了。原来飞升，不过是向天认输的另一种说法。"

##### 位面模板 05 · 功德圣境

- **剧情背景/触发条件**：进入功德位面
- **开场对话**：
  - 噬祖："金光……那些秃驴最会骗人。孩子，别信他们的话，信他们的肉。"
- **过关后剧情推进**：巢灵获得金身护体；与渡劫双修者可解锁组合技「渡劫金身」。
- **过关对话**：
  - 噬祖："他们以为放下是超脱，其实放下，就是放弃了吃。傻子。"
  - （传承提示）：传承「金身残影」——"我渡尽世人，世人渡尽我。最后一盏灯灭时我才懂，佛从不渡人，人自渡。而我，只想回那一碗斋饭的恩。"

##### 位面模板 06 · 尸海末世

- **剧情背景/触发条件**：进入异变组位面；若与已激活仙途组冲突则自动重随（见关卡策划兜底）
- **开场对话**：
  - 噬祖："尸海……这些活死人，倒比活人诚实。吃吧，他们身上也有好东西。"
- **过关后剧情推进**：巢灵觉醒尸化之力，掌握尸爆。
- **过关对话**：
  - 噬祖："这世界烂了，可烂肉里，也能长出蘑菇。别嫌弃，活下去的，就是赢家。"
  - （传承提示）：传承「尸王残影」——"我是最后一个没倒下的人。后来我也倒了，又爬起来。我爬了四十三年，不是为了活，是为了记住活过的样子。"

##### 位面模板 07 · 共生巢

- **剧情背景/触发条件**：进入共生位面
- **开场对话**：
  - 噬祖："共生……呵，说得好听。不过是把别人绑在自己身上取暖。去尝尝。"
- **过关后剧情推进**：巢灵获得寄生反水能力。
- **过关对话**：
  - 噬祖："孩子，记住，共生的另一面，是同归于尽。"
  - （传承提示）：传承「巢母残影」——"我的孩子们都死了，我把自己拆成一百个碎片，让它们替我活着。你看，我们，从未分开。"

##### 位面模板 08 · 武侠江湖

- **剧情背景/触发条件**：进入武炼组位面
- **开场对话**：
  - 噬祖："武功？凡人挣扎的样子，最好看。孩子，去，打断他们的剑。"

- **过关对话**：
  - 噬祖："他们说侠是快意恩仇。我看，不过是快意地吃。天下武功，唯快不破——快吃，才能活。"
  - （传承提示）：传承「剑圣残影」——"我一生练剑，只为等她回头。等到了那天，我已经老得举不动剑。江湖上的人都说，剑圣无名。其实我有名，她叫阿禾。"

##### 位面模板 09 · 山海洪荒

- **开场对话**：

##### 位面模板 12 · 诸天之心（全路线融合位面）

- **开场对话**：

  - 巢灵：（沉默，向前一步）
  - 噬祖："……它和我，本该是同一个。吞了它，你会成为新的噬祖。从此没有我，只有你。"
  - 巢灵：（第一次，发出声音——一声低沉的虫鸣）

  - 噬祖："……欢迎回家。"

> 来源文件：噬祖-攻击表现设计.md；以下为详细规格快照。
### 《噬祖》攻击与特效表现设计（多武器 · 多手段）

> 版本 v2.0 · 玩家是「武器库」不是「单武器」。
> 数据来源：`data/routes.js`（10 路线）、`data/skills.js`（10×6 技能）、`data/hiddenSkills.js`；设计对齐《吸血鬼幸存者》《Hades》《暖雪》的多武器同屏语言。

---

#### 一、设计原则

1. **攻击表现 = 武器的身份签名**：剑出剑气、刀出刀波、枪出子弹、雷出雷电——弹体形态跟着武器走，不同手段绝不共用弹体。
2. **多武器同屏**：玩家 Build = 叠加的多种「手段」同时生效，各自独立弹道、独立色编码、互不干扰。
3. **色编码唯一**：每条路线一个专属主色；同屏手段再多，也能从颜色+形态一眼分辨来源。
4. **可读性优先**：60+ 敌人同屏时，弹体大轮廓、高对比；命中共用统一「白闪 + 血字 + 命中特效」语言。

> **「攻击效果」定义 = 五要素一起变（换武器就整套换，不是换张图）**：
> 1. 弹道模式（直线飞刃 / 链闪 / 追踪 / 散射 / 环形 / 扇形 / 直线速射）
> 2. 弹体形态（月牙 / 子弹 / 闪电 / 魔法球 / 齿轮 / 震荡波）
> 3. 数量节奏（单发 / 多发 / 周期齐射 / 持续输出）
> 4. 命中表现（剑痕 / 火花跳弹 / 电弧炸裂 / 符文爆散 / 毒爆裂）
> 5. 主色（每武器独一色）
>
> 例：**剑** = 直线飞刃·月牙·单发→三连·剑痕·青白；**枪** = 直线速射·子弹·高频多发·火花跳弹·银蓝；**雷** = 链闪·闪电·弹射·电弧炸裂·紫白。三者五要素全不同。

#### 三·五、进化系统（局内升级视觉）

**武器和形态都在一局内进化**，随「吞噬基因 → 解锁段位（Lv1-6）」逐级变强，视觉三档明显跃迁：

| 档位 | 段位 | 视觉跃迁 | 例子（侠客·剑气） |
|---|---|---|---|
| 基础 | Lv1-2 | 单发、小、淡 | 一道细剑气 |
| 进化 | Lv3-4 | 变多、变大、颜色加深 | 三道剑气 + 弹射/顺劈 |
| 终极 | Lv5-6 | 满天飞/满屏特效 | 万剑归宗·剑阵暴雨 |

**进化视觉通用规则（所有手段统一）：**
1. **变大**：弹体尺寸随档位 +20%/+50%。
2. **变多**：弹道数量随档位 +1/+3（散弹/弹射/环绕）。
3. **加深**：主色饱和度随档位提高，终极档带辉光/拖尾。
4. **形变**：终极档形态质变（剑气→剑阵、子弹→导弹、雷电→落雷、魔法弹→全屏禁咒）。

**玩家「形态」也进化**（角色外观随路线/段位变，不是一直一个样）：
- 基础态（未激活路线）：素体巢灵。
- 激活路线：换对应皮肤（雷化/金身/侠客/机关/机甲…）。
- 高段位：皮肤带进化特效（例：渡劫高段皮肤缠绕电弧、机甲高段皮肤亮起能量管线）。

> 形态进化与武器进化绑定：皮肤 = 武器 = 路线，三者同段位一起跃迁。

#### 四、难度系统（核心）

##### 4.1 战力计算

```typescript
/** 策划折算：三属性归一化取平均 × 基因锁加成 × 装备加成。基础值 → 战力 1 */
function computePower(p: SaveData['player']): number {
  const atkTerm  = 1 + p.permAtkPct  / 100;          // 基础攻击 10
  const hpTerm   = 1 + p.permHpPct   / 100;          // 基础生命 100
  const spdTerm  = 1 + p.permSpeedPct / 100;         // 基础速度 220
  const geneBonus = geneLockPowerBonus(p.geneLocks); // 每段基因锁少量加成（见平衡表）
  const gearBonus = gearPowerBonus(p.gear);          // 装备加成（见 11 章）
  return ((atkTerm + hpTerm + spdTerm) / 3) * geneBonus * gearBonus;
}
```

##### 4.3 难度系数调整时机（每次副本结算后调用）

```typescript
interface RunResult { victory: boolean; }

/**
 * 规则（整体策划 3.2 / 5.1）：
 * 通关   → 下次 dynFactor ×(1.05~1.15) 累乘
 * 连败2-3→ dynFactor ×(0.90~0.95)
 * 钳制   → [0.70, 1.50]
 */
function adjustDynamicFactor(save: SaveData, result: RunResult): { deltaPct: number } {
  const p = save.player;
  if (result.victory) {
    const mult = randRange(1.05, 1.15);          // 随机取 +5%~+15%
    p.dynFactor = clamp(p.dynFactor * mult, 0.70, 1.50);
    p.consecFails = 0;
    return { deltaPct: Math.round((mult - 1) * 100) };
  }
  p.consecFails += 1;
  if (p.consecFails >= 2) {                       // 连败 2-3 次触发
    const mult = randRange(0.90, 0.95);
    p.dynFactor = clamp(p.dynFactor * mult, 0.70, 1.50);
    p.consecFails = 0;
  }
  return { deltaPct: -Math.round((1 - p.dynFactor) * 100) };  // UI 提示用
}
```

```typescript
const STAGE_COEF = [0.9, 1.0, 1.15, 1.3];          // 阶段 1-4
const BOSS_COEF_MIN = 1.10, BOSS_COEF_MAX = 1.15;  // 阶段 5 位面之主

interface UnitTemplate { baseHp: number; baseAtk: number; }  // 战力 1 基准

interface EnemyStats { hp: number; atk: number; }

/** 敌人实际数值 = 基准 × D × 阶段系数 × 动态难度系数 */
function buildEnemy(unit: UnitTemplate, save: SaveData, stage: 1|2|3|4|5): EnemyStats {
  const D = dungeonDifficulty(computePower(save.player), save.player.difficultyLevel);
  let coef: number;
  if (stage === 5) {
    coef = randRange(BOSS_COEF_MIN, BOSS_COEF_MAX);  // 锁定"差一点"
  } else {
    coef = STAGE_COEF[stage - 1];
  }
  const d = D * coef * save.player.dynFactor;
  return {
    hp:  Math.ceil(unit.baseHp * d),
    atk: Math.ceil(unit.baseAtk * d),
  };
}

/** 位面类型差异（关卡策划三章补充说明） */
function applySpawnStyleAdjust(plane: PlaneConfig, base: UnitTemplate, waveCount: number) {
  if (plane.spawnStyle === 'horde')   return { unit: { ...base, baseHp: base.baseHp * 0.75 }, waveCount: waveCount + 1 };
  if (plane.spawnStyle === 'single')  return { unit: { ...base, baseHp: base.baseHp * 1.5  }, waveCount: waveCount - 1 };
  return { unit: base, waveCount };
}
```

#### 五、位面随机池（权重抽取）

##### 5.1 权重规则

```typescript
/**
 * 权重（整体策划 3.4 / 关卡策划五·规则1）：
 *   已激活路线位面 ×2（刷技能导向）
 *   未激活路线位面 ×1（首进激活价值）
 *   互斥路线位面   ×0（不可抽中）
 */
function planeWeight(plane: PlaneConfig, p: SaveData['player']): number {
  // 诸天之心：不激活路线 → 权重始终 = 1（可被已激活路线加权稀释，属正常）
  if (plane.id === 'zhutian') return 1;
  let w = 0;
  for (const r of plane.routes) {
    if (p.sealedRoutes.includes(r)) return 0;            // 互斥 → 0
    if ((p.geneLocks[r] ?? 0) >= 1) { w += 2; continue; }// 已激活 → 贡献 2
    w += 1;                                              // 未激活 → 贡献 1
  }
  return w;
}
```

##### 5.2 加权随机抽取（含首进固定与互斥兜底）

```typescript
/** 开裂缝：返回本次副本位面 id */
function rollPlane(save: SaveData, rng: RNG): PlaneId {
  // 规则 3：首次副本固定机关城（教学）
  if (save.player.totalRuns === 0) return 'jiguan';

  const pool = Object.values(PLANES).filter(p => planeWeight(p, save.player) > 0);
  // 规则 2 兜底：若过滤后为空（理论不会发生，防御性处理）→ 全池重随机
  const safePool = pool.length > 0 ? pool : Object.values(PLANES);

  // 加权随机（权重累计法）
  const total = safePool.reduce((s, p) => s + planeWeight(p, save.player), 0);
  let roll = rng.next() * total;
  for (const p of safePool) {
    roll -= planeWeight(p, save.player);
    if (roll <= 0) return p.id;
  }
  return safePool[safePool.length - 1].id;
}

/** 互斥冲突兜底（规则 2）：已激活渡劫时，尸海末世权重已为 0，天然不抽中；
 *  若极端情况仍命中（配置错误）→ 替换为同组相容位面 */
function resolveConflict(planeId: PlaneId, p: SaveData['player'], rng: RNG): PlaneId {
  const plane = PLANES[planeId];
  const hasConflict = plane.routes.some(r => p.sealedRoutes.includes(r));
  if (!hasConflict) return planeId;
  const compatible = Object.values(PLANES)
    .filter(p2 => p2.id !== planeId && planeWeight(p2, p) > 0);
  if (compatible.length > 0) {
    return compatible[Math.floor(rng.next() * compatible.length)].id;
  }
  // 防御兜底（正常不会走到）：从全池随机一个
  const all = Object.values(PLANES);
  return all[Math.floor(rng.next() * all.length)].id;
}
```

```typescript

/** 三选一生成：匹配位面→路线技能池；不匹配→通用属性池 */
function rollUpgradeOptions(plane: PlaneConfig, save: SaveData, rng: RNG): UpgradeOption[] {
  const p = save.player;
  const isMatched = plane.routes.some(r => (p.geneLocks[r] ?? 0) >= 1);

  let pool: UpgradeOption[];
  if (isMatched) {
    // 该路线基因锁分支技能池（已解锁段位的技能 + 本局可学）
    const route = plane.routes.find(r => (p.geneLocks[r] ?? 0) >= 1)!;

/** 三通道边界：装备不走三选一，走击杀掉落（rollCommonGear / rollBossGear，见 9/11 章）。
 *  不匹配位面零技能，但装备掉率 ×1.5——装备是全位面共享的第三通道。 */

/** 普适加权随机（去重） */
function weightedPickNoRepeat<T extends { rarity: string }>(
  pool: T[], count: number, rng: RNG
): T[] {
  const RARITY_WEIGHT = { base: 40, feature: 40, rare: 15, legend: 5 };
  const out: T[] = [];
  const remain = [...pool];
  while (out.length < count && remain.length > 0) {
    const wOf = (x: T) => RARITY_WEIGHT[x.rarity] ?? 1;
    const total = remain.reduce((s, x) => s + wOf(x), 0);
    let roll = rng.next() * total;
    let idx = 0;
    for (let i = 0; i < remain.length; i++) {
      roll -= wOf(remain[i]);
      if (roll <= 0) { idx = i; break; }
    }
    out.push(remain.splice(idx, 1)[0]);
  }
  return out;
}
```

```typescript
/** 伪随机计数器（整体策划 4.5：连续不触发则概率递增） */
class PRDCounter {
  private count = 0;
  constructor(private baseP: number, private step: number) {}
  roll(rng: RNG): boolean {
    const p = Math.min(this.baseP + this.step * this.count, 1);
    if (rng.next() < p) { this.count = 0; return true; }
    this.count += 1;
    return false;
  }
}

/** 位面之主掉落判定 */
function rollBossDrop(plane: PlaneConfig, save: SaveData, rng: RNG): DropResult {
  const drops: string[] = ['genes'];               // 必掉基因
  // 传承：普通 20%（保底 8 次）/ 稀有 5%（保底 30-40 次，1/概率×1.5-2）
  const relicP = plane.id === 'zhutian' ? 1 : 0.20; // 诸天之心必掉「崩坏之心」
  if (relicP === 1 || new PRDCounter(relicP, relicP * 2).roll(rng)) {
    drops.push(plane.id === 'zhutian' ? 'relic_benghuaixin' : `relic_${plane.id}`);
  }
  // 超低概率技能（传说）：0.5%，PRD 递增，仅匹配位面
  if (planeChannel(save, plane) === 'skill' && new PRDCounter(0.005, 0.001).roll(rng)) {
    drops.push('legend_skill');
  }
  // 隐藏技能（禁忌级）：0.1%，PRD 递增，仅匹配位面；槽位永久替换
  if (planeChannel(save, plane) === 'skill' && new PRDCounter(0.001, 0.0004).roll(rng)) {
    drops.push('hidden_skill');                    // 具体技能见 rollHiddenSkill（10 章）
  }
  // 装备：位面之主 100% 保底稀有蓝（紫 25% / 金 5%）；不匹配位面掉率 ×1.5
  const gearRarity = rollBossGear(plane, save, rng);
  if (gearRarity) drops.push(`gear:${gearRarity}`);
  return { drops, genes: randRange(200, 300) };
}

/** 位面之主装备稀有度：保底蓝（紫 25% / 金 5%）；属性通道 ×1.5（见数值平衡表 7.5） */
function rollBossGear(plane: PlaneConfig, save: SaveData, rng: RNG): GearRarity | null {
  const isAttrChannel = planeChannel(save, plane) === 'attr';
  const mult = isAttrChannel ? 1.5 : 1;
  const roll = rng.next() * mult;
  if (roll < 0.05) return 'gold';                  // 金 5%
  if (roll < 0.30) return 'purple';                // 紫 25%
  return 'blue';                                   // 保底蓝
}

/** 非位面之主掉落：小怪 0.5% 白 / 精英 4% 白 1% 绿 / 阶段BOSS 8% 白 3% 绿 0.5% 蓝（×1.5 属性通道） */
function rollCommonGear(kind: 'minion' | 'elite' | 'stageBoss', isAttrChannel: boolean, rng: RNG): GearItem | null {
  const mult = isAttrChannel ? 1.5 : 1;
  const base: Record<string, [number, GearRarity]> = {
    minion:     [0.005, 'white'],
    elite:      [0.04, 'white'],
    stageBoss:  [0.08, 'white'],
  };
  const [p, r] = base[kind];
  if (rng.next() < p * mult) return generateGear(rng, r);  // 词条 roll 见 11 章
  return null;
}
```

```typescript
/** 生成装备：随机槽位 × 稀有度 → 词条去重 roll */
function generateGear(rng: RNG, rarity: GearRarity, slot?: GearSlotId): GearItem {
  const s = slot ?? randomSlot(rng);
  const cfg = GEAR_RARITY[rarity];
  const pool = [...GEAR_SLOTS[s].affixPool];
  const affixes: GearAffix[] = [];
  while (affixes.length < cfg.affixCount && pool.length > 0) {
    const i = Math.floor(rng.next() * pool.length);
    const key = pool.splice(i, 1)[0];
    const base = AFFIX_BASE[key];
    affixes.push({ key, value: round1(base.value * cfg.mult), weight: base.weight });
  }
  return { uid: genUid(), slot: s, rarity, star: 0, affixes, name: `${cfg.name}·${GEAR_SLOTS[s].name}` };
}

/** 装备战力加成：1 + Σ(词条数 × 稀有度倍率 × 2.5%)（数值平衡表 7.5） */
function gearPowerBonus(gear: SaveData['player']['gear']): number {
  const worn = Object.values(gear).filter(Boolean) as GearItem[];
  let bonus = 1;
  for (const g of worn) {
    const mult = GEAR_RARITY[g.rarity].mult * (1 + 0.1 * g.star);  // 强化 +1 星 ×1.1
    bonus += g.affixes.length * mult * 0.025;
  }
  return bonus;
}
```

#### 十四、编码红线（实现时必须遵守）

1. **位面不设固有强度**：所有敌人数值只由 `基准 × D × 阶段系数 × dynFactor` 生成，禁止按位面手写不同强度表
2. **D 在开副本时快照**：进入副本后不再随玩家局内成长变动（局内 Build 只影响玩家，不影响 D）
3. **不匹配位面零技能**：属性通道的三选一池不得混入任何路线技能，传说技能也只在匹配位面产出。**但装备全位面开放**——属性通道仅对技能封禁，装备掉落必须保留（掉率 ×1.5）
4. **互斥权重 ×0 必须生效**：互斥位面不允许通过随机池出现，兜底逻辑不能只弹窗不重随机
5. **难度系数钳制**：`dynFactor` 永远 ∈ [0.70, 1.50]，调整前必须先 clamp
6. **存档原子写**：所有跨局变更集中在 `finalizeRun` / `activateRoute` 完成后一次 `persistSave`，避免中途退出丢档。装备/技能槽/隐藏技能同属存档字段，禁止写入临时内存
7. **首进固定机关城**：`totalRuns === 0` 判定，全局只有这一个固定分支，此后不得有任何"新手位面保护"
8. **隐藏技能唯一性与永久性**：同一隐藏技能只可获一次（`inventory.hiddenSkills` 去重）；`hidden:true` 槽位不可被局内替换、不可被其他隐藏技能覆盖（除非玩家明确替换，见 applyHiddenSkill）
9. **装备数值闭环**：装备战力加成参与 `computePower` → 抬升 D，禁止把装备加成做成独立"局外碾压"常量，否则破坏难度进化闭环

# 《噬祖》攻击与特效表现设计（多武器 · 多手段）

> 版本 v2.0 · 玩家是「武器库」不是「单武器」。
> 数据来源：`data/routes.js`（10 路线）、`data/skills.js`（10×6 技能）、`data/hiddenSkills.js`；设计对齐《吸血鬼幸存者》《Hades》《暖雪》的多武器同屏语言。

---

## 一、设计原则

1. **攻击表现 = 武器的身份签名**：剑出剑气、刀出刀波、枪出子弹、雷出雷电——弹体形态跟着武器走，不同手段绝不共用弹体。
2. **多武器同屏**：玩家 Build = 叠加的多种「手段」同时生效，各自独立弹道、独立色编码、互不干扰。
3. **色编码唯一**：每条路线一个专属主色；同屏手段再多，也能从颜色+形态一眼分辨来源。
4. **可读性优先**：60+ 敌人同屏时，弹体大轮廓、高对比；命中共用统一「白闪 + 血字 + 命中特效」语言。

> **「攻击效果」定义 = 五要素一起变（换武器就整套换，不是换张图）**：
> 1. 弹道模式（直线飞刃 / 链闪 / 追踪 / 散射 / 环形 / 扇形 / 直线速射）
> 2. 弹体形态（月牙 / 子弹 / 闪电 / 魔法球 / 齿轮 / 震荡波）
> 3. 数量节奏（单发 / 多发 / 周期齐射 / 持续输出）
> 4. 命中表现（剑痕 / 火花跳弹 / 电弧炸裂 / 符文爆散 / 毒爆裂）
> 5. 主色（每武器独一色）
>
> 例：**剑** = 直线飞刃·月牙·单发→三连·剑痕·青白；**枪** = 直线速射·子弹·高频多发·火花跳弹·银蓝；**雷** = 链闪·闪电·弹射·电弧炸裂·紫白。三者五要素全不同。

## 二、玩家战斗架构：5 类手段叠加

玩家一局会同时持有**多种手段**，分 5 类，全部可叠加：

| 类别 | 说明 | 触发方式 |
|---|---|---|
| A. 普攻 | 自动索敌的基础攻击，**武器/弹体跟当前路线走** | 持续自动 |
| B. 附加弹体 | 普攻附带的小弹体/状态（雷击、剑气、元素、导弹…） | 随普攻概率/周期 |
| C. 主动技 | 大招级技能（全屏落雷、剑气风暴、召唤、变身…） | 手动/CD |
| D. 召唤物 | 助战单位（机关鼠、丧尸、分身…） | 主动技/CD |
| E. 范围/状态 | 溅射、震击、毒、反伤、尸爆等被动范围手段 | 攻击/受击/击杀 |

## 三·五、进化系统（局内升级视觉）

**武器和形态都在一局内进化**，随「吞噬基因 → 解锁段位（Lv1-6）」逐级变强，视觉三档明显跃迁：

| 档位 | 段位 | 视觉跃迁 | 例子（侠客·剑气） |
|---|---|---|---|
| 基础 | Lv1-2 | 单发、小、淡 | 一道细剑气 |
| 进化 | Lv3-4 | 变多、变大、颜色加深 | 三道剑气 + 弹射/顺劈 |
| 终极 | Lv5-6 | 满天飞/满屏特效 | 万剑归宗·剑阵暴雨 |

**进化视觉通用规则（所有手段统一）：**
1. **变大**：弹体尺寸随档位 +20%/+50%。
2. **变多**：弹道数量随档位 +1/+3（散弹/弹射/环绕）。
3. **加深**：主色饱和度随档位提高，终极档带辉光/拖尾。
4. **形变**：终极档形态质变（剑气→剑阵、子弹→导弹、雷电→落雷、魔法弹→全屏禁咒）。

**玩家「形态」也进化**（角色外观随路线/段位变，不是一直一个样）：
- 基础态（未激活路线）：素体巢灵。
- 激活路线：换对应皮肤（雷化/金身/侠客/机关/机甲…）。
- 高段位：皮肤带进化特效（例：渡劫高段皮肤缠绕电弧、机甲高段皮肤亮起能量管线）。

> 形态进化与武器进化绑定：皮肤 = 武器 = 路线，三者同段位一起跃迁。

## 五、代码落地（数据驱动）

1. `data/weaponAttack.js`：`WEAPON_ATTACK[route] = { projectile, color, hitFx }`，普攻弹体按当前激活路线取。
2. 附加弹体（B 类）：挂在 `eff` 上，随普攻/周期触发，渲染层按 `eff` 里的 `projectile` 字段选图。
3. 主动技（C 类）：已有 `updateActiveSkills` 钩子，触发时 spawn 对应 `projectile/summon` 视觉。
4. 召唤物（D 类）：复用 `mechAllies` 数据结构，渲染层给召唤物套对应 sprite。
5. 范围/状态（E 类）：已有 `PLANE_MECHANICS` 钩子（corpseBlast/parasite 等），补视觉即可。

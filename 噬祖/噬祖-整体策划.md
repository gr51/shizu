## 二、核心玩法设计

### 2.1 玩法概述

玩家扮演**噬祖**（无法移动的虫巢母体）派出的**巢灵**（玩家唯一单位）。每次开局：开一道**诸天裂缝**，随机进入一个**位面副本**——副本从十方位面池中随机生成，**无穷无尽、没有终点**。副本内为 5 阶段连打（阶段 1-4 常规战 + 阶段 5 **位面之主**），单局 12-15 分钟。战斗中击杀敌人掉落**基因尸体**，靠近自动吸取基因。**技能/属性/装备三通道（核心规则）**：副本位面与已激活路线匹配 → 掉落该路线专属技能（基因锁分支）；不匹配 → 只能获得通用属性、学不到该位面的技能，**但依旧掉落装备**——装备是跨路线通用成长通道，**不匹配位面装备掉率 ×1.5** 补偿（进错位面也能带装备回家继续变强）。通关带回**属性加成 / 稀有传承 / 超低概率技能 / 装备**，回巢孵化强化，再开裂缝。

### 2.2 核心循环

```
回巢强化（属性/传承/技能）
        ↓
  开裂缝（随机进入一个位面副本，无穷无尽）
        ↓
 首进位面 → 永久激活该路线基因锁（账号级）
        ↓
  单摇杆操控巢灵 → 副本内 5 阶段连打
        ↓
  吞噬基因 → 三选一（局内 Build）：
   匹配位面 = 路线专属技能（入技能槽位）｜ 不匹配位面 = 通用属性
        ↓
  第 5 阶段位面之主 → 结算
        ↓
  属性永久加成 + 传承 + 超低概率技能 + 装备 → 更强 → 循环
```

### 2.3 操作方式（详细规格）

| 操作 | 手势 | 触发区域 | 响应要求 |
|---|---|---|---|
| 移动 | 左半屏虚拟摇杆（拖拽），摇杆半径 60pt | 全屏左 60% | 位移响应 <50ms，跟手 |
| 自动攻击 | 无需操作，索敌自动攻击最近敌人 | — | 索敌切换 <100ms，攻击前摇 <80ms |
| 闪避翻滚 | 右半屏滑动（任意方向快速滑动 8pt 内） | 全屏右 40% | 触发后 0.25s 无敌帧 |
| 吞噬爆发 | 长按吞噬键（屏幕右下，88×88pt） | 固定按钮 | 长按 0.4s 触发，范围吸取 + 回血 + 狂暴 3s |
| 暂停 | 右上角暂停键 44×44pt | 固定按钮 | — |

- 热区规范：所有可点击 UI ≥ 44×44pt；摇杆边缘 10pt 内滑动仍视为摇杆操作（防误触）
- 反馈延迟红线：任何操作反馈 <50ms

### 2.4 胜负与重试

| 项 | 规则 |
|---|---|
| 过关条件 | 击杀阶段 BOSS（第 5 阶段 = 位面之主）即通过该阶段；打满 5 阶段且击杀位面之主 = 通关本次副本 |
| 失败条件 | 巢灵生命归零 = 本局失败（一命模式） |
| 失败惩罚 | 仅损失本局临时积累（局内基因锁进度、局内强化），**账号永久财产（已激活基因锁/永久属性/传承）不丢** |
| 重试机制 | 死亡后弹结算：看广告复活 1 次（复活后 1.5s 无敌 + 半血）；或直接结束本局回巢 |
| 中途退出 | 任意时刻可暂停退出，进度结算至已通关关卡（保留对应局内收益） |

## 三、关卡设计总览

> 位面模板详细设计见《噬祖-关卡策划.md》。本章为概括性框架。

### 3.1 副本结构与数量

- **副本无穷无尽**：每次开裂缝随机进入一个位面副本，副本池 = 12 个位面模板（机关城/奥法王国/奇巧迷宫/渡劫之域/功德圣境/尸海末世/共生巢/武侠江湖/山海洪荒/机甲战线/巨神界/诸天之心），**无新手/主路线/终章之分，全部平等随机**，**没有主线终点**，可无限挑战（图鉴收集是目标，不是通关线）。
- **每个副本内部 = 标准 5 阶段战斗**：阶段 1-4（常规战 + 阶段小 BOSS）→ 阶段 5（位面之主）。单局 12-15 分钟。
- **技能/属性/装备三通道（核心规则）**：副本位面路线 ∈ 已激活路线 → 三选一为路线专属技能；∉ 已激活路线 → 三选一为通用属性（无技能）。首进新位面激活对应路线后，该位面即进入"技能通道"。**装备通道对全部位面开放**：无论匹配与否，位面之主与精英/小怪都可掉落装备，不匹配位面装备掉率 ×1.5——保证"进错位面也能带装备回家继续成长"。

### 3.2 难度曲线设计（副本难度随玩家战力同步进化）

**核心公式（难度进化）**：
```
副本难度值 D = 玩家当前战力 × 难度等级系数
难度等级系数：简单 0.9 ｜ 中等 1.5 ｜ 困难 2.0
例：战力 1 → 简单 0.9 / 中等 1.5 / 困难 2.0
    战力 100 → 简单 90 / 中等 150 / 困难 200
（副本内所有敌人数值 = D × 阶段系数，位面模板不设固有难度）
```

**动态调节**（每次副本结束后调整难度等级系数）：
```
通关 → 下次副本难度 +5%~+15%（难度系数累乘）
连续失败 2-3 次 → 难度 -5%~-10%
难度系数钳制范围：0.70 ~ 1.50
```

**变量递增顺序**（每次只加一个维度）：数量 → 速度 → 复杂度 → 精度。

**单局内节奏（5 阶段）**：

| 阶段 | 时间 | 定位 | 敌人强度 |
|---|---|---|---|
| 1 | 0-2min | 教学/热身 | D × 0.9 |
| 2 | 2-5min | 适应 | D × 1.0 |
| 3 | 5-8min | 挑战（精英夹击） | D × 1.15 |
| 4 | 8-11min | 极限（复合敌群） | D × 1.3 |
| 5 | 11-15min | 位面之主 BOSS 战 | D × (1.10 ~ 1.15)（随机，锁定"差一点"） |

### 3.3 新机制引入节奏（概括）

| 引入节点 | 引入机制 |
|---|---|
| 首次副本阶段 1-2 | 移动、自动索敌、吸取基因、吞噬爆发 |
| 首次副本阶段 3-5 | 三选一升级（首进位面先教属性三选一） |
| 第 2-3 次副本 | 闪避翻滚、精英夹击机制 |
| 第 4 次副本起 | 技能/属性/装备三通道、位面主题机制、路线互斥、装备掉落 |
| 第 6-8 次副本 | 技能槽位管理（槽满替换）、装备强化合成、隐藏技能揭示 |
| 诸天之心位面 | 全部机制融合 + 多阶段 BOSS |

> 首次副本固定机关城（教学引导）；此后每次开裂缝全随机，玩家开始遇到"不匹配位面（仅属性）"与"匹配位面（技能）"的分叉。

## 四、游戏机制详解

### 4.1 基因锁系统（核心机制）

**结构**：
- 10 条路线分 5 组（每组 2 条）：仙途（渡劫/功德）、武炼（侠客/山海）、诡术（魔法/奇技）、钢铁（机甲/巨化）、异变（丧尸/共生）
- 每条路线 = 6 段基因锁（Lv1-6），每段解锁一个专属能力，第 6 段 = 路线终极技

**激活规则**：
- 首次进入某位面副本 → 永久激活该路线基因锁（账号级，跨局累积）
- 组内两条可同时激活 = 双路线（两套基因锁并行解锁，能力混合）
- 终局可集齐 10 条（图鉴向）

**技能/属性/装备三通道（成长获取硬规则）**：
- 副本位面路线 ∈ 已激活路线 → 三选一升级池为**该路线基因锁分支技能**，掉落物含路线专属技能（含隐藏技能）
- 副本位面路线 ∉ 已激活路线 → 三选一升级池为**通用属性**（攻/血/速/暴击/回血等），掉落物只有属性基因，**不产出任何路线技能**；但**装备掉率 ×1.5 补偿**
- 装备通道全位面开放：无论匹配与否都能掉落装备（见 4.7 装备栏系统），装备是跨路线通用成长通道
- 含义：想学山海的本事，就得激活山海路线、进山海位面；进丧尸位面只能"长肉"（属性），学不会丧尸的活计——但**照样能捡到装备**，进错位面也有收获。

**互斥规则（永久互斥）**：

```
仙途组(渡劫/功德)  ⇆  异变组(丧尸/共生)   4 对全互斥
钢铁组(机甲/巨化)  ⇆  武炼组(侠客/山海)   机甲↔山海、巨化↔侠客 互斥
诡术组(魔法/奇技)  ——  中立，可与任何非对立路线组合
```

- 永久互斥：激活渡劫后，丧尸/共生永远无法激活；图鉴显示"已封印 · 你的血脉拒绝了它"
- **无重置机制**：一条账号一路走到黑（宿命感 = 留存钩子）
- **首次教学**：首次副本固定为机关城（完成移动/索敌/吸基因教学），此后全部随机

**基因锁能力示例**（每条路线 6 段，完整表见关卡策划/数值章节）：

| 路线 | Lv1 | Lv3 | Lv5 | Lv6 终极技 |
|---|---|---|---|---|
| 渡劫 | 攻击附带小雷击 | 雷链弹射 2 目标 | 天雷护体反伤 | 「九重雷劫」全屏落雷 |
| 功德 | 击杀回血 | 金身减伤 15% | 业力反伤 | 「金身不灭」3s 无敌 |
| 丧尸 | 吸血 5% | 死亡敌人尸爆 | 尸潮召唤 | 「尸山血海」召尸潮 |
| 共生 | 吸取敌方攻速 | 寄生小怪反水 | 母体分裂 | 「共生体」双核心 |
| 侠客 | 暴击 +5% | 连招强化 | 剑气外放 | 「万剑归宗」剑气风暴 |
| 山海 | 体型 +10% | 践踏 AOE | 兽魂附体 | 「饕餮巨口」吞噬一切 |
| 魔法 | 弹幕 +1 | 元素附加 | 法力涌动 | 「禁咒」全屏奥术 |
| 奇技 | 机关召唤 | 陷阱强化 | 傀儡分身 | 「天工开物」机关大军 |

| 巨化 | 攻击范围 +20% | 震地击 | 体型巨化 | 「顶天立地」巨神形态 |

### 4.2 战斗机制（核心机制）

- **自动索敌**：巢灵自动攻击最近敌人，可被三选一升级强化（攻击模式/范围/弹道）
- **吞噬**：敌人死亡掉落基因尸体，靠近自动吸取（吸取半径 40pt，吸取动画 200ms）；长按吞噬键 = 范围爆发（吸取周围所有尸体 + 回血 + 狂暴 3s，CD 30s）
- **闪避翻滚**：0.25s 无敌帧，可穿怪
- **精英夹击**：第 3 阶段起精英怪会绕过战线直扑巢灵（偷家机制），制造攻防压力
- **位面主题机制**：每位面有专属战场机制（如渡劫位面随机落雷、机甲位面炮台阵列、丧尸位面尸爆连锁）

### 4.3 局内 Build（三选一升级）

- 触发时机：每阶段 BOSS 击破后 + 累积吞噬达阈值（每副本 1-2 次）
- 选项来源（技能/属性双通道；装备为第三通道，不走三选一，走击杀掉落）：
  - 匹配位面（路线已激活）→ 三选一 = 该路线基因锁分支技能（2-3 个选项随机）
  - 不匹配位面（路线未激活）→ 三选一 = 通用属性强化（攻击/生命/速度/暴击/吸血等），**不出现任何路线技能**
- 稀有度分布：基础 40% / 特色 40% / 稀有 15% / 传说 5%（传说 = 路线特有超低概率，仅匹配位面产出，改变玩法）
- **技能槽位**：局内获得的主动技能/召唤类技能装入**主动槽**（默认 2 格），被动强化装入**被动槽**（默认 2 格）；槽位满后获得新技能 → 弹窗选择替换（被替换技能销毁）；基因锁被动段（Lv1/3/5）自动生效**不占槽**，仅主动段（Lv5 召唤类、Lv6 终极技）占主动槽。详见 4.6。
- 升级间隔：首次升级 30-60s，之后每 60-90s，单局总计 6-12 次

### 4.4 跨局成长（Roguelite 留存）

| 系统 | 说明 | 获取方式 |
|---|---|---|
| 永久属性 | 攻/血/速按比例永久加成 | 吞噬基因按比例结算留存（局内吞噬量的 5% 转化为永久属性点） |
| 稀有传承 | 保底掉落，自带"位面残影"短文（碎片叙事） | 保底 = 1/基础概率 × 1.5-2；如概率 5% → 30-40 次内必出 |
| 超低概率技能 | 分支专属，第 6 段终极技外的稀有变体 | PRD 伪随机保护，连续不触发概率递增 |
| 装备 | 跨路线通用词条（攻/血/速/暴击/减伤等） | 任意位面掉落（不匹配位面 ×1.5），词条按价值折算进战力 |
| 基因锁 | 路线能力树（上文 4.1） | 首进位面激活 + 局内充能 |

### 4.5 随机性控制

- **输入随机为主**：副本布局/敌人/路线基因在进入前生成，玩家看到结果再决策
- **PRD 伪随机**：传承/稀有技能掉落连续不触发则概率递增，消除极端脸黑
- **保底机制**：传承保底次数 = 1/概率 × 1.5-2
- **每日挑战固定种子**：全服同副本布局，分数可比 + 可分享

### 4.6 技能槽位与隐藏技能

**技能槽位（局内 Build 载体）**：

| 槽位 | 数量 | 装载内容 | 规则 |
|---|---|---|---|
| 主动槽 | 2 | 主动技能（终极技/召唤/爆发类） | 基因锁主动段与局内三选一主动技能入此槽 |
| 被动槽 | 2 | 被动强化（增伤/回血/攻速等） | 局内三选一被动强化入此槽 |
| 基因锁被动段 | — | Lv1/3/5 被动能力 | 自动生效，不占槽位 |

- 槽位满后获得新技能 → 弹窗列出"替换哪个槽位 / 放弃新技能"；被替换技能销毁，不入传承库
- 同一技能不可重复装载；换出后未学的技能保留在"待选池"中，后续三选一仍可能再次出现

**隐藏技能（禁忌级，稀有度高于传说）**：

- 稀有度：隐藏（Hidden）> 传说（Legendary），**获得后永久替换某一个技能槽位**——该槽位局局开局即带此技能，**跨局永久生效**
- 获得方式：仅匹配位面掉落（隐藏技能必属某路线），PRD 伪随机保护；基础概率 0.1%（传说之上）；首通诸天之心必得 1 个自选
- 作用：**永久替换技能槽位**——获得隐藏技能时选择一个空槽或已有技能的槽位，将该槽位永久锁定为该隐藏技能；此后该槽位不再参与局内替换/三选一，开局自动装备
- 上限：每槽位最多 1 个隐藏技能；4 个槽位全部刻印隐藏技能 = 大成就（诸天共鸣）
- 不可出售/不可丢弃/不可重复获得同一隐藏技能；图鉴新增"禁忌"稀有度栏

### 4.7 装备栏系统（跨路线通用成长）

**定位**：装备是唯一不依赖路线激活的成长通道。**任何位面都掉装备**，不匹配位面（属性通道）装备掉率 ×1.5——解决"进错位面学不到技能"的挫败感，任何副本都能"带装备回家"。

**装备栏结构（6 槽位）**：

| 槽位 | 名称 | 主属性倾向 |
|---|---|---|
| 1 | 噬爪 | 攻击 / 暴击 |
| 2 | 甲壳 | 生命 / 减伤 |
| 3 | 虫冠 | 攻击 / 技能冷却 |
| 4 | 足器 | 速度 / 闪避 |
| 5 | 基因核心 | 吸血 / 回血 |
| 6 | 传承饰品 | 混合词条 / 掉落加成 |

**装备稀有度与词条**：

| 稀有度 | 词条数 | 基础数值倍率 | 掉落来源 |
|---|---|---|---|
| 普通（白） | 1 | 1.0 | 任意位面小怪/精英 |
| 精良（绿） | 2 | 1.3 | 精英 / 阶段 BOSS |
| 稀有（蓝） | 3 | 1.6 | 位面之主保底 |
| 史诗（紫） | 4 | 2.0 | 位面之主概率 |
| 传说（金） | 5 | 2.5 | 位面之主低概率 + 合成 |

- 词条池：攻击+X% / 生命+X% / 速度+X% / 暴击+X% / 攻速+X% / 吸血+X% / 减伤+X% / 回血+X%/s / 技能冷却-X% / 吸取半径+X%
- 词条按价值折算进战力（见 5.1 公式），装备越强 → 战力越高 → 副本难度 D 同步进化，数值闭环不失控

**装备获取与强化**：

| 途径 | 说明 |
|---|---|
| 位面掉落 | 任意位面：小怪 0.5% / 精英 4% / 阶段 BOSS 8% / 位面之主 100%（保底稀有蓝） |
| 不匹配位面 | 装备掉率 ×1.5（属性通道补偿） |
| 合成 | 3 件同稀有度任意装备 → 1 件更高稀有度（白→绿→蓝→紫→金） |
| 强化 | 同槽位同名装备 +3 件 → 该装备 +1 星（词条数值 ×1.1/星，上限 +5 星） |
| 分解 | 多余装备分解为"装备精华"，用于合成保底 |

**与双通道的关系（核心规则补充）**：技能通道 = 匹配位面专属；属性通道 = 不匹配位面专属；装备通道 = 全位面共享。三者叠加构成完整收益预期，位面卡展示"可获奖励：技能/属性/装备"。

### 5.1 核心数值公式

```
巢灵战力 = 基础属性(攻/血/速) × 永久加成系数 × 基因锁加成 × 装备加成
装备加成 = 1 + Σ(已装备词条价值折算)（词条按攻/血/速等值折算，公式见《噬祖-数值平衡表.md》）
副本难度值 D = 巢灵战力 × 难度等级系数（简单 0.9 / 中等 1.5 / 困难 2.0）
敌人战力 = D × 阶段系数 × 动态难度系数
阶段系数（5 阶段）：0.9 / 1.0 / 1.15 / 1.3 / BOSS 公式
BOSS 公式：BOSS 战力 = D × (1.10 ~ 1.15)
单次伤害 = 攻击力 × 技能倍率 × 暴击(1.5×) − 目标防御(若有)
```

### 5.2 基因经济（局内）

| 参数 | 数值 |
|---|---|
| 基因产出速率 | 40-60 基因/分钟 |
| 小怪掉落 | 5-10 基因 |
| 精英掉落 | 30-50 基因 |
| 阶段 BOSS 掉落 | 80-120 基因 |
| 位面之主掉落 | 200-300 基因 + 传承碎片 |
| 一次升级所需 | 局内递增：80 → 120 → 170 → 230 → 300 … |

### 5.3 永久属性转化

```
局内吞噬基因总量 → 结算转化：攻 +2% / 血 +2% / 速 +1%（每次结算，三选一属性）
单局上限：三种属性合计 +3%
```

### 5.4 传承掉落

| 稀有度 | 基础概率 | 保底次数 |
|---|---|---|
| 普通传承 | 20% | 8 次内必出 |
| 稀有传承 | 5% | 30-40 次 |
| 超低概率技能 | 0.5% | PRD 递增（300 次内期望 1-2 个） |
| 隐藏技能（禁忌级） | 0.1%（匹配位面专属，槽位永久替换） | PRD 递增（500 次内期望 1 个） |
| 装备 | 见 4.7（位面之主 100% 保底稀有） | 位面之主每局必掉 |

### 5.5 成长天花板与数值膨胀控制

- 每次升级数值提升 ≥10%（可感知）
- 副本难度随玩家战力同步进化（难度等级系数天然满足），设置战力上限（单维成长上限 500%）
- 数值表逐位面详见《噬祖-关卡策划.md》数值详表

## 七、游戏流程

```
首次进入：
  启动 → 一句话世界观（"诸天崩坏，裂缝涌现。噬祖，醒来。"）
  → 直接进入首次副本（机关城）→ 打完 5 阶段 → 结算
  → 回巢（主界面）→ 引导开第二次裂缝

正常循环：
  主界面(虫巢) → 开裂缝(随机副本) → 裂缝生成动画 → 副本内 5 阶段连打
  → 死亡(看广告复活 1 次 或 结束) / 通关 → 结算页
  → 回巢：查看进化图鉴 / 传承库 / 强化巢灵 → 再开裂缝（无穷无尽）

每日挑战：
  固定种子副本 → 全服同布局 → 成绩排名 → 分享
```

## 九、技术实现要点

### 9.1 推荐技术栈

- Cocos Creator 3.x（TypeScript）
- 微信小游戏 SDK + 抖音小游戏 SDK（适配层封装，双端一套代码）
- 本地存档：`localStorage` / 微信 `wx.setStorage` 封装
- 无后端；每日挑战种子用固定数值种子 + 本地时间对齐

### 9.2 核心算法/逻辑

| 模块 | 实现要点 |
|---|---|
| 副本随机生成 | 种子随机（进局固定 seed）：位面池抽取（权重：已激活路线×2 / 未激活×1 / 互斥×0）→ 位面主题 → 地图布局 → 敌人波次表 → 技能/属性通道标记 |
| 自动索敌 | 每帧扫描半径内最近敌人，目标切换 100ms 冷却；攻击前摇可打断 |
| 难度进化 | 难度等级系数持久化在存档；副本难度值 = 玩家当前战力 × 等级系数，通关/失败后按 5.1 公式调整 |
| 基因锁系统 | 配置表驱动（10 路线 × 6 段能力，JSON）；激活/互斥用状态位图 + 互斥规则表 |
| 三选一 Build | 从当前路线能力池按稀有度权重随机 3 个，去重；主动技能入主动槽、被动强化入被动槽，槽满触发替换 |
| 技能槽位与隐藏技能 | 槽位状态存档持久化；隐藏技能 = 槽位永久刻印标记，开局自动装载，不参与局内替换 |
| 装备掉落与合成 | 位面掉落权重（不匹配 ×1.5）→ 装备对象（6 槽位 × 5 稀有度 × 词条 roll）→ 合成 3→1 / 强化 +1 星 / 分解精华 |
| PRD 保底 | 每类掉落独立计数器（传承/技能/装备/隐藏技能），未触发则概率递增 |
| 吞噬系统 | 尸体对象池；吸取 = 圆形检测 + 缓动回收 + 飘字 |
| 震动手感 | 微信/抖音振动 API 封装 + 视觉抖动降级 |

### 9.3 性能优化

- 敌人/尸体/飘字全部对象池化，同屏上限 60 单位
- 卡通 Q 版素材压缩：纹理 ≤ 1024，图集合并
- 双端启动体积目标 ≤ 4MB（首包），资源分包加载
- 特效粒子 LOD：低端机降粒子数，保留核心反馈

### 9.4 适配说明

- 竖屏安全区适配（刘海屏 `safe-area`）
- 摇杆热区随分辨率缩放，最小可点区 44×44pt
- 双端分享卡片、激励视频广告位（复活/双倍奖励）统一封装
